# 任务上下文与经验联合选择：开发协议

日期 2026-11-13（北京时间），API 调用前冻结。研究阶段为有界开发，不预先承诺优势。

## 五组和信息来源

full（A）：完整已观测状态和历史，无经验；filtered（B）：强依赖闭包，无经验；full_memory（C）：完整状态历史＋普通词袋余弦 Top-2；filtered_memory（D）：同一强依赖闭包＋与 C 相同的 Top-2；joint：同一检索候选，按任务/当前条件筛选适用经验，再补齐它引用的上下文记录。

同一直接重规划模型、系统提示、动作 schema、任务契约、域约束、后缀上限、反馈验证和执行器。所有任务要求、禁止操作、时间锚点完整保留。依赖闭包保留手部状态、阻挡对象、当前区域占用（含空区域的明确观测）及所有相关时间范围内事件，不能通过削弱 D 制造优势。

经验开启组拥有同一可访问记忆库。无经验组是明确的模块消融，不将其视作同信息最强对照。主比较 joint 对 D；A—D 作组件分析。实际进入模型的信息差异来自选择算法，不来自多给 joint 观测、标签、额外调用或答案。

## 经验来源与限制

仅 2 条人工归纳经验：目标占用与首次历史事件不确定。源自已经归档的真实被拒候选，及结构化反馈后被验证通过的修正候选。原始来源为 revision_recovery_model_20261113_v1 与 revision_recovery_direct_diagnostic_20261113_v2 的 direct 记录。每条保存来源 SHA、实例/尝试定位；运行前重新用旧任务和旧验证器重放失败与修复。不是新物理经验，不是自动归纳，更不证明一般因果规律。

模型只看到通用条件化建议，不看到来源案例名、完整旧答案、原始状态或标签。建议不得覆盖当前任务和事实。Top-2 是正相似度词袋余弦检索，不强制塞入零相似度条目；各经验组文本格式相同。joint 可过滤全部经验。暂不使用 embedding 付费调用或 LLM 总结。

## 任务及预算

8 个人工构造开发实例：正常、持物目标阻挡、受保护阻挡、经验不适用、过去顺序冲突、未知首次事件、明确新轮次、已完成。背景历史是合法合成动作，不冒充机器人日志。域仅两物体、三位置、一只手；当前任务契约已接受，本实验不测自然语言契约翻译。

源码预先固定另 20 个未用于本轮经验库的新组合验证实例，包括交换目标、部分完成、受保护目标、阻挡必经点、旧证据与新锚点、未知但有共同后缀、容量冲突。它们仍来自相同机制和同一域，不称新域泛化。案例标签由作者事先指定；有界精确求解仅核对标签，不为某一模型臂生成答案。

开发 8×5=40 对，每对最多 2 次请求，最多 80 次；模型 deepseek-v4.1-flash，temperature=0.1，seed=0，thinking=False，max_tokens=2048，传输重试 0，timeout=60 秒，workers=2，动作最多 8。所有失败、截断、解析错误、候选拒绝计入分母与成本。调用前保存代码、全部案例、记忆库、提示和调用顺序。只读密钥配置，不归档密钥。

新 20 例先冻结为未运行的候选验证集。是否发起后续模型比较，先检查接口与评分审计及方法可识别性，不按开发中哪个案例对本方法有利挑选实例。后续若运行，为 100 对、最多 200 次请求，另存阶段，不混为 28 个独立新机制。

## 接受、反馈和评分

任务契约固定，模型只输出绑定版本/摘要的 status 与 actions。ready 的原始后缀必须在当前有限域中合法并满足完整任务和所有历史分支。非 ready 声明通过共享有界求解器核验，但不能用求解器计划替换模型输出。所有组收到同样具体的动作前置条件或历史可行分支诊断；诊断不读取作者标签。拒绝后只允许共同预算内重发。

符号下发逐步调用已有票据门槛，命令下发不改历史，受控环境观测后才追加事件。此处不是 MuJoCo 或真实 RGB 比较。正确 conflict/need_observation 单列，不能算可完成任务完成。空后缀可表示已完成。

主报告首次正确处理、预算内最终正确处理、可完成例符号完成、拒绝/错误 ready、错误停止、请求/token（含重试）、控制动作。上下文记录数量与字节量只作选择描述，实际 token 用 API 账单。无自动事实检索准确率标签，不把算法自身的适用判定当独立人工真值。

离线审计所有背景历史删除前后，原始和预测后缀的 monitor 结果是否一致；检查任务/约束保持、信息入口与标签隔离。模型首次和反馈后各自归档，不能只报最终成功。经验人工整理成本未知，分别披露，不声称包含人工构建的端到端费用更低。

## 运行前已经发现的边界

8 个开发与 20 个新组合案例中，强依赖闭包已经包含经验引用的相关事实；joint 目前没有增加新的上下文记录，等价于“强依赖筛选＋经验适用条件门控”。本轮可以测这个门控与普通 Top-2 的差异，**不能证明经验驱动上下文补全有独立收益**。

若五组都能完成、差异只来自删掉旧背景记录或减少经验条数，应分别归因；若与简单门控完全同构，不称新的联合规划算法。这个可识别性边界在 API 前记录，不能看见结果后重新命名贡献。
