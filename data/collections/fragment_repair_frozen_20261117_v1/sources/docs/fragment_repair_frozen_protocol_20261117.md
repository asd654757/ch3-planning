# 第二阶段：冻结证书指导修订，不在线缩核

本阶段在第一阶段结果出来后提出，不能当作最初预注册的同一假设。第一阶段全部结果保留在 fragment_repair_pilot_20261117_v1。其来源公式组 828 次完整求解、总时间中位数 3.958 秒，均劣于枚举的 418 次、2.707 秒；在线缩核的开销抵消了收益。

本阶段只取消目标任务上的在线核心提取，复用已有证书和相同的修订集合、排序、硬约束、历史保持机制、H=8。比较六组：枚举、来源并集公式、精确来源公式、逐候选证书重检、旧十核心的精确来源公式、旧十核心的逐候选重检。前两类公式只是不同强度的拒绝条件；精确来源公式与逐候选重检应完全等价。不向任何组提供目标任务的最优修订标签。

固定两个既有工作负载：
1. 连续执行回放中的全部 187 次非 ready 判断；
2. 原三物体 768 个目标任务中的全部非 ready 判断，以原 frozen reference.json 的状态选择，不按本阶段结果筛选。

对各工作负载独立报告全部候选、实际规划器调用、认证加载和全流程耗时，3 次计时、循环组顺序；不与第一阶段计时跨轮混比。新建域、独立动作下界、必要的原证书重新认证、原始任务解码、修订算法均计费；不需要证书的枚举组不承担证书加载费。原非 ready 决策作为共同输入免收重复查询。所有组按相同规则返回最小删除数、同序修订与原规划器 ready 后缀。未修订项、历史及 since 不变。

计时外用无下界、无证书的原规划器，按候选顺序审计至首个 ready，证明没有更优/排序更早的有效候选；审计每个返回后缀。对每个授权删除子集独立核验精确来源公式与逐候选重检等价。

已有来源获取、学习和建库成本本轮不重新收取，因此只讨论**已有库之后的查询阶段**成本，不能声称包含学习成本的端到端收益或新型通用修订算法。两个工作负载均已用于过去研究，它们是冻结复验而非全新盲测。若精确公式不能优于逐候选重检，则否定其独立计算贡献；普通知识复用的收益可单独保留。
