# 状态缓存对照的共同匹配器复验

第一版三组实验全部十轮及独立覆盖审计保留在 fragment_state_cache_comparison_20261117_v1 和对应 analysis 中。第一版状态缓存先查旧库，再单独提取一次 features 查新缓存；完整方法已经合并编译。虽然覆盖结论有效，但额外特征提取和账本验证会使缓存对照多付查询费用，第一版时间不能作为最终公平性能证据。

本复验在新计时前保存。将状态缓存的旧核心和 96 个来源对称状态点合并，使用与 full 完全相同的 RegionBank.evidence 原始函数代码、特征提取、逻辑包含消减和证明构造。保留原状态缓存每个点的认证，不新增状态、不扩展目标绑定。其余完全复用 fragment_state_cache_protocol_20261117.md 的十轮、顺序、来源阶段、三组任务、扰动、计时边界、完整校验和负结果保留规则。

使用独立驱动注入新状态缓存类，原协议、实验程序和第一版源码全部不修改。第一版的 source/state_cache/full 文件及原始时间均可回查；第二版计时是最终依据，不能挑两版更快的组进行拼接。

新实现必须在全状态检查和候选任务上与第一版状态缓存保持完全相同的逻辑命中，且 evidence 方法代码对象与全方法完全相同。完成 871 项原回归测试基础上新增匹配器等价测试，再开始计时。不能为恢复总费用优势更换任务或扩大目标数量。
