# 相同失败证据下的状态绑定核心缓存对照

本协议在新对照覆盖分析和计时前保存。沿用已见连续任务的全部 32 条序列、384 次修订，模板、扰动、H=8、原后端和派发链保持原样。属于回顾性的机制消融，不称为新盲测或物理实验。

## 三个固定方法

1. fixed：旧十个认证核心、独立物体动作下界、来源精确缓存、合法后缀复用及原规划器。
2. state_cache：fixed 加八个来源失败的小核心，保留完整来源状态；允许全部物体排列和 green/return 互换的领域对称变换，允许当前任务包含额外义务。table/hand 不作容量类型交换，每个变换后的核心和状态均重新核验。该对照能够迁移物体名称，不是完整任务字符串匹配。
3. full：fixed 加同样八个核心，沿用已有类型化绑定与全部状态认证、紧凑距离证书和最大状态守卫。

八个来源失败固定为原来源过程中产生新核心的 source-0008、0016、0019、0020、0029、0067、0091、0115。不增加失败、不从目标任务提取核心、不根据本轮效果替换来源。

## 来源与费用边界

为隔离迁移机制，三组每轮都从同一个 fixed 来源处理流程获取信息：相同 384 个来源任务、相同旧十核心和公共下界。它应得到 333 次完整求解和同一 333 条来源精确缓存。state_cache/full 对相同八个失败执行同一贪心删除最小化；full 再做全绑定全状态认证，state_cache 仅认证上述对称状态下的核心。fixed 不收取不执行的提取费用。

这与上一轮来源阶段在线学习并逐渐过滤任务的流程不同，不能直接把两轮总费用相减。这里的总费用专门回答“共同证据流、相同失败信息时，认证推广是否值得额外成本”。八个失败的选取是已冻结来源记录的重放，不声称新的失败发现算法。

每轮来源从新的隔离域开始，包括域构建、初始证书读取及重认证、下界、来源求解、实际核心提取、该组认证、缓存和证书序列化。随后在线阶段从另一个新隔离域重新读取产物、重认证并运行原连续任务循环。来源、准备和循环费用均分别记录，并在本轮相加得到总算法费用。公共数据不重复充当新任务样本。

状态缓存认证共享已有批量求解引擎；完整方法同样共享。不能给某组设置假延迟、额外验证或独享目标缓存。执行时三组均禁止学习和缓存增长，所有 ready 后缀仍校验。状态缓存命中也受当前状态、历史必要条件、语义版本和预算约束。

## 计时和验证

固定十轮、三组，以六种方法排列循环调换顺序。每轮每组均重新执行实际来源阶段和载入重认证，不沿用上一轮热的图搜索缓存。保留全部轮次，不按快慢筛选，不改任务规模。来源与目标参考核对、逐步动作回放、JSON 轨迹哈希及不同方法语义轨迹比较都在计时外执行。计时期间不运行其他测试或分析。

主指标：完整后端调用、相对 fixed 和 state_cache 的额外覆盖；其中任务修订与受扰恢复分别统计；来源费用、在线准备费用、内部决策费用、执行循环费用、在线费用及三阶段总费用。报告十轮中位数、每轮配对差值及胜负次数。十轮是工程重复，不把它当十个独立任务集进行泛化显著性推断。

完整方法相对状态缓存没有额外覆盖时，应明确现有序列没有证明状态泛化必要；若完整方法成本更高，应保留该负结果。能支持的贡献限于本轮已实证机制，不能用本实验单独声称论文新颖性或物理成功率提升。
