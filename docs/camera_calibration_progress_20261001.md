# 固定相机标定验证

新增 corner2 标定导出、光学坐标转换、显示图两轴翻转还原与三维点投影函数。导出的执行坐标是 `mujoco_world`，不是 `robot_base`；后续控制器必须显式匹配或提供刚体转换。

实际场景运行记录：
- v1：当前 MuJoCo 不暴露 cam_orthographic 属性，异常退出，无有效结果。
- v2：修复版本兼容问题，9 个预设平面点投影—反投影通过。
- v3：增加独立渲染检查，9 点最大往返误差 4.44e-16 m；4 个物体中心投影均位于对应渲染 segmentation 包围框内。

公开 calibration.json 仅包括固定相机参数、坐标系与平面假设。物体位置与 segmentation 只用于 evaluator-side 投影检查，结果另存 evaluation_only，不生成在线目标。

检查仍较粗：中心在包围框内不等于亚像素对齐，代数往返也不能独立证明相机参数完全正确。当前仅验证 corner2、480×480、现有透视相机；不支持动态腕相机或任意相机标定配置。几何误差、物体高度和像素选择仍可能导致操作失败。

相关测试共 56 项通过。没有模型调用或机器人抓取，无新成功率结论。下一步接固定控制器前仍需明确目标像素来源、目标高度假设、工作空间，以及独立的持物和结果检查。
