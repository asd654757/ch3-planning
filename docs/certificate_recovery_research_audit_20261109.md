# 恢复决策：联合重抓验证与投稿创新审查

## 本轮判断

评价目标是“可投稿小论文的方法贡献”。目前仍未达到这一标准。
本轮补齐了一个实际恢复能力，也把证据依赖写进了可核对的决策模型；
不能据此声称前瞻优于强规则，或把标准状态抽象改名为新算法。

## 实际恢复：新的9次开发运行

脚本：`scripts/pilot_joint_regrasp.py`。
原始数据：`data/collections/joint_regrasp_dev_20261109/`。
固定seed1010–1012，各运行normal/released/precontact，一共9次。
首轮执行前冻结配置、manifest及5个关键源文件快照；所有分配运行均保留。
全部条件关闭反馈dropout，专门验证物理恢复能力，不与此前遮挡pilot混为一谈。

| 开发条件 | 路由 | 任务完成 | 恢复控制步数 |
|---|---|---:|---|
| normal | 保留已被视觉支持的抓取，继续放置 | 3/3 | 183、182、182 |
| released | 联合判据授权，开爪抬手、新图重绑定、重抓、重新验证、放置 | 3/3 | 319、317、317 |
| precontact | 同一联合判据与重抓流程 | 3/3 | 320、317、317 |

每回合一次episode reset、0次模型API调用。恢复阶段累计2454个显式控制步；
包含30步夹爪诊断以及主动观察。终局评分另计，不向策略反馈物体真值。
这是开发可行性试验，没有强规则/前瞻的配对方法比较，也没有推断总体成功率。
预留正式seed960–979仍未使用。

重抓没有复用只允许接触前调用的`retract_open()`，也没有伪造precontact标志。
新宏动作在单独的联合门控下执行，任何改变世界的动作之前撤销旧观测，
动作之后重新取得图像绑定；重抓控制器完成后还必须重新取得持物证据才能放置。

### 必须保留的反例与范围

旧诊断`data/collections/recovery_contact_evidence_dev_20261109/`中，
normal的3次实际持物也出现了很小的夹爪间距，原几何判据错误地支持了空手。
原数据和原源文件快照保留。现有`aperture_evidence()`从不输出空手支持，
它只描述闭合诊断；视觉目标不随动也不单独等于空手。

新的重抓授权还要求：初始已知空手、唯一可能抓取的是蓝色目标、固定标定支撑面、
没有新物体或未记录操作、目标可见且在与手分离的主动探测中保持静止、
不存在正向持物证据矛盾。这是封闭fixture假设，不能迁移成开世界空手判断。

这9次恢复由一个简单规则足以组织：正向持物→继续；满足联合重抓门控→重抓；
其余→停止。9/9支持新恢复入口可执行，不支持规划算法有优势。

## 可计算原型：证据、预算与动作效果

代码：`ch3/repair/certificate_recovery.py`。它是研究原型，尚未在线派发机器人动作。
输入是明确给定的有限转移模型、每个动作的证据契约与多资源预算。
模型状态为`(b, C, B, h)`：潜在物理状态的belief、当前有效的正向证据集合、
剩余预算与搜索深度。证据名称不是模型语言输出，也不是物理真值。

动作a的准入要求`requires(a) ⊆ C`且完整准入cap可被B支付。
观察结果o和实际消耗r共同用于后验更新；证据更新为：

    C' = (C \ invalidates(a)) ∪ produces(a, o)
    B' = B - r
    Q_h(a) = P_model(terminal_success | b,a)
             + Σ_(nonterminal o,r) P_model(o,r | b,a) V_(h-1)(b',C',B')
    V_h = max(0, max_a Q_h(a)),  V_0 = 0

不引入手调加权奖励；优化模型内的预算约束完成概率。模型预测成功不是运行时完成证据。
运行时仍需真实门控。对于未建模的正概率假设，原型停止。

### 未来相关证据切片的保值条件

令R为h步内乐观可达动作的全部证据需求。计算R时忽略证据准入，并反复使用当前B
而不扣减预算，得到超集；因此它不会删除一个可能变得有用的需求。
缓存前只保留`C ∩ R`。

在以下假设下，切片保留所有动作价值及固定tie-break下的根决策：

1. 模型与契约在规划器生命周期内固定；转移、观察概率、消耗与终局奖励不依赖被删证据，只依赖给定物理状态与动作。
2. 证据只经契约的requires/invalidates/produces影响动作许可与更新。
3. 消耗非负，子节点预算不增大；搜索深度有限。

证明按h归纳。h=0所有价值为0。h>0时，每个当前可能动作的requires都在R中，
因此切片前后准入一致、观察概率和后验一致。每个子节点的相关需求包含在当前R中：
它的支持状态是当前一步乐观可达的子集，预算不增，剩余深度少1。
同一观察下，产生和撤销操作不会将被删差异变成子节点相关差异。
由归纳假设子值一致，故每个Q值和根决策一致。

R不是最小相关集；计算R本身也有成本。没有测出真实运行时间收益。
这只是已声明模型内的等价性论证，不是物理安全证明。
当前字符串token尚未实现通用对象绑定版本、TTL、独立证据源或并发修改语义。

新增测试包含100个随机转移模型，与独立、未压缩的观察树逐项比较动作价值；
另检验相同观测不会泄漏潜在状态、动作ack不能恢复被撤销的持物证据。
随机模型测试不是100次机器人运行，也不是模型标定。
相关测试30项通过，最终完整回归`PYTHONPATH=. python -m pytest -q`共491项通过。

## 一手文献核对：哪些不能单独当作新颖性

以下为初步范围审查，并非穷尽检索。判断是我们的研究判断，不是原论文给本项目的评价。

| 机制 | 已核对一手来源 | 本项目的判断 |
|---|---|---|
| 条件有效性与动作完成分离、依赖修复 | [LOGIV，方法III及附录A](https://arxiv.org/html/2610.40016v3) | 与“旧支持失效后局部修复”接近，不能只换术语 |
| 追加证据历史、可修订状态、撤销依赖结论 | [REMM，方法III及附录A](https://arxiv.org/html/2610.12710v1) | 证据撤销和冻结执行器上层恢复本身已有明确先例 |
| 工具认证连续参数后才执行 | [TAMPAgent，方法3](https://arxiv.org/html/2611.03584v1) | 认证后执行与belief规划本身不够区分 |
| 预先编译恢复分支、在线触发 | [AgentChord，III-C至III-E](https://arxiv.org/html/2605.11951v1) | 预备恢复图不是单独的新贡献 |
| 暂时删去条件无关变量并保留策略价值 | [Trey Smith，2007博士论文第7章CIVA](https://publications.ri.cmu.edu/storage/publications/pub_files/pub4/smith_trey_2007_2/smith_trey_2007_2.pdf) | 直接限制了“证据切片保值就是新算法”的说法 |

CIVA与当前原型并非逐项相同；当前带有限预算和证据契约。但给旧思想增加这些维度，
加上一个等价性证明，仍不足以直接认定独立方法新颖性。需要真正不同的计算方法或
明确的新问题结构，以及相对同等信息、预算、执行器的强基线收益。

## 下一研究门槛

此前的接触后重抓入口已经补齐；现在的瓶颈是：可用证据几乎直接指定了唯一合理动作。
不能把规则没有获准使用的新动作只给前瞻，也不能把多个真实步骤拆给前瞻、合并给规则
后再把horizon差异写成贡献。

应优先验证“恢复动作会改变后续可验证性”这一具体机制：至少两条都合法且能完成任务的
恢复路径，需要在保留抓取/重新定位/重新建立绑定上有真实不同的成本和后果；预算和
观察结果应改变最佳路径。所有简单规则、调优规则和规划器都取得相同恢复选项与证据。
如果同一简单规则始终最好，就保留这一结论，不启动正式样本扩增。

投稿通过门槛还需要：冻结开发/评价拆分；强预算规则和调优浅层决策树；相同模型的
精确有限搜索作为小实例参照；证据失效成本消融；模型误差敏感性；至少独立任务或布局
上的迁移评估。仅仅比无状态的“总是重规划”好，不足以支撑当前目标。
