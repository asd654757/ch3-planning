# 收敛主线：大模型控制过程中的可靠执行与剩余任务恢复

本文件覆盖此前路线图中继续扩展任务语义模块的建议。已有数据保留，不修改原始结果。当前没有因此启动新的批量实验。

## 1. 研究问题

大模型生成计划后，实际执行状态可能偏离预期。如何识别不再可执行的后续动作，基于当前反馈修复剩余任务，并避免未经支持的继续执行？

主链：大模型计划 → 结构化校验 → 固定控制器执行 → 当前观测/执行反馈 → 继续、有限再观测、剩余计划修复或停止。

本文贡献是验证与恢复机制，不是新的视觉定位器、语言解析器或运动控制器。不再增加语义解析模块；不训练 ACT，不在小论文中接入 AD-Flow。底层策略接口保留，供大论文后续使用。

## 2. 已有证据与归因

### 持续执行故障（已完成，仿真状态反馈）

原始数据：`data/collections/persistent_recovery_protocol_formal_30seed_20260929.jsonl`，270 次运行，30 个 seed × 3 类扰动 × 3 种比较方法。

| 扰动 | 无恢复 | 重试旧后缀 | 当前状态符号搜索 |
| --- | --- | --- | --- |
| 抓取超时 | 0/30 | 28/30 | 28/30 |
| 放置超时 | 0/30 | 28/30 | 28/30 |
| 抓取后受控掉落 | 0/30 | 0/30 | 29/30 |

核对：所有记录 reset_count=1；三类扰动各比较方法均实现 30/30；VLM 调用数为零。成功定义含连续 10 步目标距离、开爪与位置稳定检查。

掉落后原剩余动作是 place，当前状态需要重新 pick 再 place。这是剩余序列真正改变的证据。重新 pick 不属于重复执行已完成前缀：历史上的抓取已完成，但其持物效果后来被掉落破坏。必须保留历史，不得据历史假定当前仍持物。

**限制**：这里是确定性搜索、单物体、仿真内部状态；不能写成大模型恢复性能，也不是视觉闭环证据。超时条件搜索与重试相同，不证明规划修复优于重试。

复核命令：`python scripts/audit_core_recovery_evidence.py`，仅读数据，不调用模型或仿真。

### 新视觉持续场景（已完成，但性质不同）

- 早期接近超时：已支持回撤与恢复，动作序列通常不变，应归因于受支持的重试，不主张大模型优势。
- 任务切换与有界再观测正式集：150 次运行；临时缺失时再观测设置 30/30，无额外再观测 15/30；规则与模型剩余规划均 30/30。主要支持再观测价值，不证明大模型优于规则。任务切换不是执行故障。
- 非法目标注入后一次 R1_FROM_STATE 放置成功：是小规模计划错误诊断，未形成配对物理性能结论。
- 语言释义 pilot：移至辅助诊断，不作为本轮主实验，也不继续增加语义模块。

## 3. 下一项实验：最小的掉落后大模型恢复对照

先复用 `scripts/sim_persistent_recovery.py` 的同场景掉落协议，而不是另建复杂视觉系统。新增接口前先验证状态反馈、剩余动作生成、校验与执行边界。以下设置是待实现，不是已完成结果。

比较方法：

1. 旧后缀重试：不读取反馈修改计划，掉落后尝试旧 place；明确它是反馈无适应对照。
2. 当前状态直接大模型重规划：与本文机制共享状态、能力、目标与基础安全校验；不故意提供过期状态制造优势。
3. 验证与恢复机制：检查观测与剩余计划，使用当前状态生成并验证新的剩余序列；失败后有限回退或安全停止。
4. 当前状态符号搜索：保留为精确模型下的参考，不回避其可能更强、更便宜。

各方法共用控制器、初始计划、扰动、执行预算与终点评分。比较 2 与 3 前必须明确唯一机制差异、调用上限与失败处置；若仅包装名称不同，不开展冗余实验。不可删除基础执行安全检查来制造对照风险。

先做 3 个 seed 的接口 pilot，包括无扰动和掉落；暂不直接跑 formal。保持一次初始化，恢复不 reset。记录实际下发动作、当前事实、执行历史、模型原响应、拒绝原因、调用与控制步数。模型输出拒绝与扰动未实现均保留在任务分母，另报扰动实现子集。

进入 formal 的条件是协议可审计，而不是本方法赢得足够明显：状态确实改变；恢复从当前状态出发；已失效的 place 不直接下发；物理评分独立；方法间信息与预算差异明确；模型不能生成时诚实记失败。

此阶段只能称“执行状态反馈恢复”。若后续替换为 RGB 证据，需要单独验证掉落/空手观测接口；不能把 unknown 默认为空手，也不能用仿真真值在线授权后标成视觉恢复。

## 4. 成功与失败如何写

- 旧后缀失败、当前状态恢复成功：证明反馈适应与剩余任务更新的必要性，不单独证明路由贡献。
- 直接重规划与本文机制相同：报告安全处置、调用成本和边界，不强称性能领先。
- 符号搜索更强：承认精确模型下的优势；大模型负责已有语言/视觉接口，不主张普遍必要性。
- 回退带来提升：同时报告首轮成功、回退比例及调用成本。
- 未知状态停止：计安全停止，不计任务完成或恢复成功。

论文仍定位“大模型机器人任务规划的可靠执行与反馈恢复机制”。持续场景、新视觉与旧分段 benchmark 分表展示，不合并总体成功率。
