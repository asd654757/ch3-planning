# 抓取失败证据前置模块：离线诊断

## 实现范围

新增 `failed_pick_evidence`，检查图像目标在探测期间保持初始像素位置、手有足够运动、目标与手有投影间隔。输出仅为 `target_not_following_supported` 或 unknown。**不输出 hand_empty、on(object,table)，不授权重抓，不修改现有在线执行决策。**

这是用于剩余任务恢复的局部观测前置环节，不是通用视觉定位或状态估计算法。二维静止不证明桌面接触，不跟随手不证明手里没有其他物体。

当前启发式阈值仅面向固定 480px 校准场景：最大初始漂移 3px、目标运动 2px、手运动至少 4px、各帧手目标距离至少 12px。它们及已有图像用于开发诊断，不是经独立测试集验证的误判率。采用更换相机、尺度、物体颜色时不能沿用鲁棒性结论。

## 实际执行的检查

`scripts/audit_failed_pick_evidence.py` 重新读取已保存的 RGB（撤销显示双轴翻转），结合原记录的手部本体投影。没有读取模拟器对象位置、评分或奖励；每张反馈图像保存 SHA256。没有新模型调用或新仿真任务。

结果保存于 `data/collections/failed_pick_evidence_audit_20261002_v1.json`：

- 三个正常抓取记录：本模块均为 unknown（原持物模块则支持 holding）。没有被标成失败证据。
- 跳过抓取控制：可支持“目标不随手运动”；仍然不支持空手，不授权重抓。

这是四份已有记录的离线检查，不是四个新实验，不计入正式样本量。相关自动测试 87 项通过；覆盖缺失/非有限输入、近手歧义、静止手、目标中途移动后回到初始位置等拒绝情况。

## 仍未完成

没有跑通实际抓取失败后的恢复；没有实现安全回撤与重试；没有获得新的性能优势结果。不能将本次诊断写成“闭环恢复成功”。

下一步：记录新鲜的夹爪/手部本体反馈和有限场景前提，定义受支持的重抓前置条件；实现有界回撤（非碰撞安全保证），确认位姿/控制预算后重观测；只在恢复起点证据成立时调用当前状态重规划。另一物体可能被拿起、视觉缺失或证据冲突时保持 unknown 并停止。若无法可靠建立该起点，缩小实验为早期接近阶段超时，不假装覆盖所有抓取故障。
