# 中等与较难：冻结配对执行协议

数量解释：每个难度30个seed，两个方法各运行30次，即每难度60次执行，合计120次。

## 条件

- medium：第二次实际搬运的place目标x偏移+0.045m；第一次观测成功交付保留，模型不得再操作仍满足目标的对象。偏差由RGB释放/目标证据确认后授权重规划。
- hard：同样第二次偏差，只有观测支持偏离目标后发布预声明的用户目标变更，交换两个目的区域。旧已完成对象若不再满足新目标就不再禁止移动，但历史不能重放。两个方法都得到新目标。
- 变更不是模型推断，不称自然故障；hard不要求保护已不满足新目标的对象。
- 两方法同状态信息、图像入口、模型、初始共享候选、安全门、控制器、评分及两次非初始请求上限。最大四次搬运：两次原尝试，hard最多两次后续交付。
- 对仍满足目标对象的保护是计划动作禁令和最终目标评分，不是连续接触动力学安全证书。

## 样本与启动门槛

独立smoke seed169、170，每难度四次，共八次；不纳入正式分母。需实际RGB触发、历史记录正确、请求保护对象与变更匹配、候选可执行。未知与失败不放宽评分。

正式medium seed171–200，hard seed201–230，均固定30个配对。不得按结果挑样本或在批次中修改协议。先冻结再运行。

报告总任务成功、观测未知、安全拒绝、首次模型候选接受、拒绝后纠正、恢复实际完成与token成本。共享初始调用单列；旧简单条件与本轮不合并分母。若同样饱和，诚实报告未观察到反馈增益。
