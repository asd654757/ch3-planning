# 释放后偏离目标恢复 pilot 核验

seed133–138，三设置18次全部完成。直接重规划5/6、v6反馈修复5/6、无执行恢复0/6。共16次真实调用：6次共享初始规划、两个恢复方法各5次执行恢复请求，均一次接受。

seed134三方法均因observed_goal_unknown_no_completion停止，没有评分放宽或更换seed。其他5对同一偏差由RGB释放/目标检查触发，不使用终端真值；请求历史没有成功交付记录，当前对象位置为observed_support。恢复后两次真实交付都满足终端独立评分。

三方法每seed初始请求、图像哈希、候选输出一致；非初始预算无超限；成功历史为两次交付，不计失败的首次搬运。回归测试37项通过。门槛通过意味着该有限分支可以接受正式评估，不意味着已证明广泛恢复鲁棒性。

按已冻结协议扩为seed139–168，三个设置90次执行；保留未知与失败在完整分母中。报告“观测支持触发后的条件恢复率”时必须与总任务成功率分开，不能排除未知样本后只报成功。

这是受控first-place指令偏移造成的实际物理执行偏差，不是自然故障。结果能检验“观测当前状态→大模型剩余计划→同场景继续执行”的作用，不能单独证明错误反馈优于直接重规划，也不能证明开放世界视觉估计或持物故障恢复。
