# 完整见证改为精确距离证书的成本复验

本协议在紧凑证书计时前写入。第一轮批量搜索已经核对全部 15,402 个完整后缀，仍保留了总费用慢约 17% 的结果。本轮继续优化证书表示，不改变任务、样本数、强对照或自动学习逻辑。

## 变更与安全条件

- 每个核心、每个类型绑定仍覆盖所有 34 个合法状态。存储精确 minimum_actions 向量及预算内冲突掩码，替代逐状态重复保存完整可行后缀。
- 不减少认证状态，不抽样，不直接信任序列化距离。载入按相同精确图搜索重新计算每一字段；任何距离或掩码改动均应拒绝。
- 审计时仍可从距离重构每个完整最短后缀，逐项匹配旧证书。机器人可执行后缀仍由原 full-task decide 和精确缓存返回。
- certify_region 的实现/数据格式发生变化，应如实记录；核心提取、变量规范化、状态范围、编译匹配、回退和完整任务规划的逻辑保持不变。
- 两组使用相同紧凑格式和批量引擎。图构造、序列化读取、距离核验和缓存准备费全部计入。

## 固定复验

沿用 fragment_batch_protocol_20261116.md 的三轮来源、三轮冻结目标、顺序、费用边界和所有负结果保留要求。复用同一计时程序，仅注入新的领域认证工厂，归档工厂和驱动源码，禁止改动来源任务/预期核心或目标子集。

先逐项验证旧 18 个证书的全部绑定、状态判断、掩码，以及所有原始动作后缀；紧凑格式中可行状态距离必须等于原最短计划长度。来源应复现相同 8 个新核心和全部真实调用来源；目标保持额外覆盖 66 次、无误拒、336 个 ready 后缀全部合法。

本轮是已见任务上的等价计算优化，不冒充新的盲测或新增理论贡献。总费用仍较慢时如实报告，不再扩大目标批量摊平构建费用。
