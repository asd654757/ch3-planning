# 第一点完成：当前方法与已有冲突学习的实质区别

## 判断

**目前不能把“从失败提取约束、带状态条件迁移”本身认定为已成立的独立方法新颖性。**已有论文覆盖了这些基本思想。新增强对照后，来源部分状态泛化已解释当前方法在本批受扰恢复中的全部额外命中；完整部分状态 nogood 的并集与当前拒绝掩码逐绑定完全等价。

当前实现仍有实际价值：相对来源局部条件，拒绝域计算更完整；相对本轮显式 nogood 包络实现，省去了构造大量条件的步骤，三阶段时间中位数较低。其证据属于有限域知识编译和系统实现层面，尚不足以直接宣称新的通用失败学习原理、开放世界能力或成熟的小论文方法贡献。

这次结论修正了此前只对比固定规则和完整状态缓存得到的较乐观判断；旧数据保留，新强对照应优先用于论文主张。

## 文献核对完成了什么

详细机制与原始出处见[已有方法核对表](fragment_method_prior_art_20261117.md)。关键重合包括：

- [COAST，IV-B](https://arxiv.org/html/2405.08572v1)已将细化失败转成约束，并具有随阻挡状态变化的碰撞约束。因此“状态变化后启停失败约束”不是空白。
- [Score-space](https://arxiv.org/abs/1807.09962)已研究跨问题迁移搜索约束。因此“迁移约束而非整条计划”不是独家概念。
- [状态空间 nogood 学习](https://fai.cs.uni-saarland.de/hoffmann/papers/ai17.pdf)已学习逻辑条件识别相似死状态，其主要保证不依赖解长度上界。当前预算冲突的保证与之不同。
- [Conflict-driven interface / GraphNLP](https://arxiv.org/abs/2211.15275)已提取和存储最小不可行连续约束子集，再反馈给逻辑规划。因此小核心和复用数据库本身不能作为首创。

这些不是对原论文所有代码和实验的复现；本轮不声称击败 COAST、hC 或 GraphNLP 的整套系统。当前任务是已知有限符号模型中的有界可行性判断，未包含那些论文全部连续优化、运动采样或无界死状态问题。

## 新增的强对照

[协议](fragment_partial_nogood_protocol_20261117.md)在求解与计时前固定。三组使用相同八个来源失败、相同 384 个来源任务、相同 32 条连续序列和 384 次修订，H=8。每轮都实际运行共同来源处理、相同核心最小化、该组认证、序列化、重新载入重认证与执行循环。

| 方法 | 状态条件与绑定范围 |
|---|---|
| 来源部分状态 nogood | 从来源位置事实中删除无关条件；允许所有物体与目标的双射换名；逐一核验所有合法补全，保留所有包含最小充分条件 |
| 完整部分状态 nogood 包络 | 同样核心和绑定，在位置等式语言中生成全部包含最小充分条件，覆盖全部可表示的拒绝状态 |
| 当前完整拒绝域方法 | 同样核心与绑定的精确拒绝状态掩码和距离证书 |

三组均有同一旧十核心、独立动作下界、333 条来源精确缓存、合法后缀复用、历史必要条件提取和原后端。三组直接使用相同 RegionBank.evidence 函数代码，仅一次特征提取，没有重复验证惩罚基线。目标阶段不学习、不扩缓存，没有更换任务、扩大批量或删慢轮。

来源部分对照固定相同任务核心，仅泛化位置等式条件；没有复现任意联合任务/状态子句学习、负文字学习或 hC 抽象细化。完整包络保留全部最小条件，并非最少规则集合或最优符号表示。因此该比较可检验当前机制，但不能证明胜过所有已有冲突学习实现。

## 覆盖和正确性

| 方法 | 在线完整求解 | 片段提前识别 | 相对当前方法尚需多求解 |
|---|---:|---:|---:|
| 旧完整状态缓存，含物体及容量一区域对称换名 | 283 | 18 | 19 |
| 来源部分状态 nogood，含全部目标绑定 | 276 | 25 | 12 |
| 完整部分状态 nogood 包络 | 264 | 37 | 0 |
| 当前完整拒绝域方法 | 264 | 37 | 0 |

后两组在所有 34 个状态上的编译匹配表完全相同，不只是本批任务碰巧得到相同命中数。三组共用的下界提前识别 134 次、后缀复用 1,183 次；均完成 197 次修订，初次不可行 166 次、执行中暂停 21 次。三组执行轨迹与之前完全一致，误拒及非法 ready 后缀均为零。

**当前方法相对来源部分 nogood 的额外 12 次命中，全部位于任务修订后的首次判断；受扰恢复阶段没有额外命中。**因此不能沿用“比一般部分状态冲突学习多解决受扰恢复问题”的主张。相对原状态缓存的优势中，已有一般化条件学习可以解释相当部分。

为了区分绑定范围与状态条件删除，另做不计时的覆盖诊断：完整状态缓存若同样允许全部目标绑定，其完整求解数为 **280**；再允许删除位置事实降到 **276**。因此旧缓存 283 到新来源部分对照 276 的七次改善中，三次来自绑定扩展，四次来自同绑定范围下的状态条件删除。这是事后覆盖控制，没有冒充额外计时组。

## 表示等价的独立证据

当前八个新核心共有 270 个声明绑定，其中对称重复合并后为 225 个不同具体核心。对照按具体核心合并重复绑定，未被强迫保留重复规则。

独立审计使用优化前原始完整 BFS 证书作为参照，验证：

- 270 个声明绑定的 **9,180 个状态结果**与当前精确距离证书一致，对应 225 个不同具体核心的 7,650 个状态结果；
- 来源部分条件的 **168 条**规则、完整包络的 **960 条**规则，其合法补全集全部非空、全部不可行；
- 每条规则删除任一保留位置事实后，都能在原 BFS 证书中找到可行反例；来源规则也确实来自允许的来源事实子集与换名；
- 每个具体核心的完整 nogood 条件并集恰好等于当前方法的拒绝掩码；
- 全部 **1,618 次决策**及 **1,431 个 ready 后缀**另经完整规划器与执行语义核验。

条件长度分布为：来源规则 24 条一事实、144 条二事实；完整包络 48 条一事实、744 条二事实、168 条三事实。该范围只针对这批核心和绑定，不是对任意机器人任务的普遍规律。

固定 K、H，拒绝域 B(K,H) 的每个状态都能由完整位置等式描述。所有充分且包含最小的部分状态条件的析取恰好覆盖 B；直接保存 B 的位掩码与保存这些条件，是同一个有限集合的不同表示。本轮既给出该数学关系，也逐项核验。

**相同逻辑结果本身不否定可能存在的计算贡献**；但若要以此投稿，需证明适用域计算、复杂度、空间或实际规模上的实质改进。当前小域、相同匹配表和约 4% 的构建费用差异，还不足以把表示差异提升为通用算法突破。

## 完整费用与实现差异

以下为本轮预定十轮的中位数，单位毫秒。分项中位数分别计算，不能直接相加。

| 指标 | 来源部分 nogood | 完整 nogood 包络 | 当前完整拒绝域 |
|---|---:|---:|---:|
| 来源获取、提取、认证及写盘 | 795.8 | 835.2 | 791.3 |
| 在线载入、重认证与准备 | 153.8 | 226.6 | 121.2 |
| 内部决策 | 1,166.8 | 1,059.9 | 1,087.0 |
| 完整执行循环 | 2,043.2 | 1,929.6 | 1,966.7 |
| 在线准备加执行 | 2,182.5 | 2,154.8 | 2,086.8 |
| 来源加在线总费用 | 2,970.9 | 2,990.6 | 2,878.7 |
| 总费用均值，含全部慢轮 | 3,101.1 | 3,151.7 | 2,871.3 |
| 序列化产物字节，含公共缓存和旧证书 | 316,191 | 348,397 | 362,215 |

当前方法相对来源部分对照减少 **12 / 276 = 4.35%** 完整求解；总费用中位数降低 **3.10%**。相对完整包络没有额外避免求解，总费用中位数降低 **3.74%**。两组比较的总费用配对轮次均为 10/10 较快。

差异主要在来源构建与重新载入：当前方法无需显式构造 960 条最小条件。完整包络的决策中位数反而略低，且它与当前方法使用相同匹配代码和相同条件表，所以不能宣称独特的在线决策推理能力。当前产物也没有更小，不能笼统宣传内存压缩优势。

完整包络保留所有最小条件，未进一步求最少覆盖，也未用 BDD 等其他压缩形式。这里的 3.74% 是针对这个具体实现与固定工作负载的工程结果，不是相对所有冲突学习方法的复杂度优势。部分轮次存在明显波动，全部保留；十轮是同一任务集的计时重复，不是十个独立泛化实验。

## 论文可写与不可写的边界

| 内容 | 当前判断 |
|---|---|
| 失败提取小核心、变量换名、条件化复用本身 | 已有先例，不能作为首创 |
| 比来源局部条件得到更完整的有限拒绝域 | 有证据，额外 12 次首次修订判断 |
| 比一般部分状态 nogood 更强的受扰恢复覆盖 | 本批数据不支持，额外为零 |
| 比完整 nogood 具有独特可表达性或逻辑覆盖 | 不支持，匹配表完全等价 |
| 用距离/掩码跳过大量显式条件构造 | 具体实现有成本证据，属于知识编译/工程差异 |
| 独特的历史约束学习贡献 | 未隔离证明，历史预处理由对照共享 |
| 真实失败的因果发现、未知物理规律学习 | 未实现，来源是已知符号模型的预算内规划失败 |
| 开放世界或稳定物理端到端提升 | 未验证 |

完成第一点后的建议是：**现阶段将其保留为可解释、可核验的失败知识编译模块和章节实验内容；不把它单独包装为已确认的新型失败泛化算法。**本轮确认了已有思想的重合、具体表示差异和覆盖/成本边界；尚未证明独立的小论文方法新颖性。

这不等于所有工作无价值。任务修订、证据账本和可执行回退已经形成可靠实现，新的强对照也使论文主张更可信。但若目标仍为独立方法小论文，需要一个不能被当前一般 nogood 表示与已知编译方式直接解释的增量；继续增加同分布任务或换说法不会补上这一点。本轮不另开新研究方向。
