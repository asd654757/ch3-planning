# 收束实验：显式许可下的成组任务替换

本轮按[事先写定的协议](/root/autodl-tmp/ch3-planning/docs/fragment_purpose_repair_protocol_20261117.md)补齐了一个有明确边界的模块：在任务配置明确允许时，以物体为组互换两个同类目标，寻找改动条款数最少的可执行任务。验证结束，采用逐候选核查版本；不继续扩充修订算子。

**目的保持的条件。**实验新增的是一份绑定当前快照的合成分流许可：对于所列物体，green、return 都是该物体允许的单位容量暂存位，table 不属于此类。此许可是任务配置输入，不是从失败、颜色或大模型自动推断出的语义事实。它不表示原机器人场景中这两个区域天然等价。每个物体可以独立选择允许的区域映射；如果任务目的要求跨物体共用同一个实体区域，必须另加硬关系，不能套用本配置。

同一物体所有涉及 green/return 的 at 和 visit 成组互换，因此同目标关系和不同目标关系均在该物体内保留，不会将两个不同途经点合并。所有条款、物体、ID、kind、顺序引用和保护要求保留，table 要求不变。已被 confirmed 或 unknown 历史放置证据支持的相关 visit 会锁定整个物体的替换。未改项 since 原样保留，真正替换的要求沿用原 apply_replacement 的当前 cursor 生效规则。历史账本、当前状态不变。

这比任意删要求有更明确的任务许可边界，但仍是“给定许可后的合法修订”，并未证明自动理解了自然语言用户目的。

**问题与对照。**使用全部 187 次冻结连续执行失败和全部 432 个冻结静态失败，H=8。它们附加了上述新许可，是原冻结输入的受控变体。每个物体最多一种成组互换，三物体最多八个候选；候选按改变条款数及 `(ID, 新目标)` 排序。各组的候选、许可、原非 ready 信息、独立动作下界、共同来源 ready 后缀缓存均相同。缓存命中必须重新逐动作、逐历史分支检查，不能凭缓存标签宣布 ready；目标集不学习、不扩缓存。

三次计时循环/反转顺序。费用包括每组实际域构造、下界、缓存、所需证书重新认证、任务解码、候选生成及搜索。已有来源获取和建库费未重新计入，因此以下仅为已有库之后的查询阶段结果。

| 方法 | 连续回放完整求解 | 连续回放总费用中位数 | 静态任务完整求解 | 静态任务总费用中位数 |
|---|---:|---:|---:|---:|
| 标准最小代价搜索＋共同下界/缓存 | 170 | 1.931 秒 | 659 | 3.402 秒 |
| 同搜索＋旧十核心 | 123 | 1.607 秒 | 312 | 1.959 秒 |
| 同搜索＋来源部分状态 nogood | 109 | 1.505 秒 | 227 | 1.600 秒 |
| 同搜索＋十八核心逐候选核查 | **87** | **1.301 秒** | **185** | **1.398 秒** |
| 同十八核心＋组选项特征编译 | 87 | 1.363 秒 | 185 | 1.509 秒 |

采用十八核心逐候选核查，相对标准搜索完整求解减少 **48.82% / 71.93%**，总费用中位数减少 **32.62% / 58.90%**；相对旧十核心，新增八个来源失败片段再减少 **36 / 127 次**完整求解，总费用中位数减少 **19.03% / 28.61%**。三次配对轮次中，这两组比较均为 3/3 更快。只有三次重复和两个固定工作负载，不作跨平台稳定性或总体统计显著性主张。

共同动作下界本身已很强：标准搜索分别靠它拒绝 739 / 1,321 个候选，来源 ready 缓存分别命中 0 / 2 次。十八核心的 420 / 1,350 次片段命中中，部分也可被共同下界拒绝；相对标准搜索净少求解的是 **83 / 474 次**，不能将全部命中当成净收益。

**部分状态强对照。**相对来源局部部分条件，当前库额外减少 22 / 42 次完整求解，费用中位数低 13.53% / 12.60%。连续回放中这 22 次包含首次修订 19 次、受扰恢复 3 次。这里是新许可下的替换搜索，不是上一轮原任务恢复判断，不能据此改写上一轮“恢复额外命中为零”的结论。

相同核心的完整部分 nogood 包络与十八核心在全部 34 个合法状态上的匹配条件表仍完全相同。因此它能复现 87 / 185 次求解的逻辑覆盖，本轮没有证明超越一般完整 nogood 推理。它作为逐表等价审计，未冒充额外的计时组。

**结果完整性。**所有方法得到相同的最优修订：

| 结果 | 连续回放 | 静态任务 |
|---|---:|---:|
| 存在许可内的可执行成组替换 | 30 / 187 | 84 / 432 |
| 当前 H 与许可内无可执行替换 | 157 | 348 |
| 改一项条款的建议 | 26 | 60 |
| 改两项条款的建议 | 2 | 17 |
| 改三项条款的建议 | 2 | 7 |

连续回放的 30 项建议中，18 项在任务首次修订时，12 项在动作受扰后的判断时。其余 505 次失败不通过删除目标或重写历史来制造修复；结论仅是当前许可及 H=8 内没有 ready 替换，不是任务在物理世界永远不可行。

114 项建议都是合成许可下修订后的任务结果，不能称为执行成功了 114 个原始任务。所有方法建议数相同，性能收益体现为寻找同样建议时的计算费用，未提升该候选集合的可修订率。

**正确性与最优性。**独立参照程序不使用新候选构造器，直接枚举许可对象的全部开关，用原 apply_replacement 构造契约。逐一对齐新实现的候选集合与代价，再通过原完整规划器做 3,510 次无剪枝判断，确认首个 ready 之前不存在更便宜或同代价排序更早的可行候选。后缀另用原动作转移与历史监测检查。

所有 3,820 个授权组替换都核对了特征编译与原 features 相等、拒绝结果与原 bank.evidence 相等。替换会引入原任务没有的原子和冲突：其中 133 / 204 个候选在原任务未命中片段时新命中了片段，不能只检查原任务的冲突核心。

新增 16 项测试覆盖不同途经点不合并、历史 confirmed/unknown 锁定、过期许可拒绝、条款保留、既有顺序约束、生效时间与原 API 一致，以及损坏 ready 缓存不得授予执行资格。完整回归 **913 passed**。代码未接入现场控制器；本轮无模型 API、训练或物理动作。

**负结果与取舍。**组选项编译没有减少完整求解，逐候选版本在三个配对轮次均较快，其总费用中位数比编译组低 4.51% / 7.34%。因此采用简单的逐候选版本，不将该编译器当作创新或主方法。上轮在线缩核较慢的负结果同样保留。本轮不再追求更复杂的搜索。

**新颖性边界。**[Automata-based Optimal Planning with Relaxed Specifications](https://arxiv.org/abs/2107.13650)已用用户许可的带权编辑系统表达替换、删除及分组，并求解最小松弛策略。[最小规约修订](https://arxiv.org/abs/1404.2289)也已研究接近原任务的可实现修订。因此“等价替换＋最小代价”本身不能作为首创。本轮未复现那些论文的完整系统，不声称性能胜过它们。已有 nogood 完整包络能解释本轮覆盖，独立小论文算法新颖性仍未成立。

**停止决定。**至此已有可运行方法、历史和许可边界、最优性核验、来源知识增量、强 nogood 对照、全费用与负消融。适合停止增加机制，按[第三章收束稿](/root/autodl-tmp/ch3-planning/docs/ch3_method_freeze_20261117.md)整理章节；可写为历史保持的任务修订和失败知识复用框架及其有限模型证据，不写成已确认的全新冲突学习理论或开放世界解决方案。
