# 新方向先导：失败知识辅助的最小可执行任务修订

本轮已实现并验证一个新增用途：当当前任务没有 ready 后缀时，利用既有失败片段，寻找允许删除范围内、删除数最少的任务修订，并附原规划器验证通过的后缀。保留项的内容、ID、有效时间 since 均不变；历史账本不重写。只输出建议，没有接受修订或执行机器人动作。

**有新的功能和知识复用收益，但尚未确认新的通用算法创新。**最小规约修订、核心引导纠错和隐式击中集已有充分研究；本轮精确来源公式也与逐候选重新匹配证书等价。不能因为比无知识枚举快，就重新把已有冲突学习包装成首创。

**为什么选这个方向。**它直接延伸“从失败提取可验证、可迁移约束片段”：失败知识不仅用于回答能否执行，还用于搜索一项经过检查的改动建议。复用原后端，不训练模型、不切平台。预算自适应本轮先排除为独立创新，因为既有证书已保存最短动作数，按当前 H 设置阈值只是自然复用。

**具体机制。**对固定状态和历史，程序知道每个必要原子由哪些任务要求支持。例如，未满足的 at(蓝,绿) 和未完成的 visit(蓝,绿) 都可能要求未来 place(蓝,绿)。删除其中一个原始要求不一定能消除该必要条件。

令 D 是拟删除的要求 ID 集，S(a) 是支持必要原子 a 的全部要求 ID。要破坏一个当前生效的冲突片段 K，必须满足：

`OR_{a in K} [ S(a) subset_of D ]`

对所有命中片段取 AND。硬要求不属于可删集合。该式可以一次编译，再筛选修订候选；较弱对照仅要求从片段涉及的要求并集中删一项。剩余候选仍由原规划器判断，证书未命中不等于可行。

这是当前特征提取的精确删除前像：在状态、历史和 since 固定、只做删除时，每个必要特征是其保留支持者的析取；片段触发是这些特征的合取。删除不能引入先前不存在的特征。因此精确来源式与逐候选重新提取特征、匹配同一库的拒绝结果相同。这个逻辑关系用于正确性，不作为新定理宣传。

**第一阶段的负结果。**[原协议](/root/autodl-tmp/ch3-planning/docs/fragment_repair_pilot_protocol_20261117.md)和原始结果全部保留。尝试在目标任务失败后继续贪心提取最小核，但当前任务要求只有 3–6 项，额外缩核不划算：

| 187 次失败上的方法 | 完整求解调用，含缩核 | 总时间中位数 |
|---|---:|---:|
| 按删除数枚举，含共同独立动作下界 | 418 | 2.707 秒 |
| 在线核心引导 | 1,184 | 5.187 秒 |
| 迁移精确来源式，再在线缩核 | 828 | 3.958 秒 |

这否定了“当前小任务上继续在线缩核会更好”的实现假设。以上不是 MaxHS 或专业 MCS 求解器的复现，不能据此断言核心引导方法一般较差。

**第二阶段设计。**在观察到上述负结果后，另写[后续协议](/root/autodl-tmp/ch3-planning/docs/fragment_repair_frozen_protocol_20261117.md)，仅复用冻结证书，不在目标任务上缩核。没有把第二阶段冒充最初预注册假设。

冻结两个工作负载：连续执行回放中的全部 187 次非 ready 判断；另一个既有 768 任务集中的全部 432 次非 ready 判断。它们都是过去使用过的冻结复验集，并非全新盲测。H=8。forbid、before 和按 ID 排序的首个 at 设为不可删除，其余要求单位代价。这是明确的实验权限配置，不是从自然语言自动推断的用户偏好。无合法最优修订时返回 no_authorized_repair。

所有方法候选集合、排序、原规划器、独立动作下界及初始非 ready 信息相同。费用包括新建域、必要的证书重新认证、任务解码、搜索和后缀生成。枚举组不加载用不到的证书。旧十核心与新十八核心分别计其实际加载费。每组重复三次、循环顺序，计时外审计。

| 方法 | 连续回放完整求解 | 连续回放总时间中位数 | 静态任务完整求解 | 静态任务总时间中位数 |
|---|---:|---:|---:|---:|
| 枚举＋独立动作下界 | 418 | 2.660 秒 | 1,133 | 4.056 秒 |
| 来源并集式＋十八核心 | 290 | 1.829 秒 | 596 | 2.201 秒 |
| 精确来源式＋十八核心 | 287 | 1.801 秒 | 581 | 2.140 秒 |
| 逐候选重检＋十八核心 | 287 | 1.815 秒 | 581 | 2.171 秒 |
| 精确来源式＋旧十核心 | 357 | 2.301 秒 | 766 | 2.874 秒 |
| 逐候选重检＋旧十核心 | 357 | 2.322 秒 | 766 | 2.901 秒 |

相对枚举，精确来源式完整求解减少 **31.34% / 48.72%**，总时间中位数降低 **32.29% / 47.23%**。相对旧十核心，新增八个失败片段使完整求解再减少 **70 / 185 次，即 19.61% / 24.15%**；总时间中位数降低 **21.73% / 25.55%**。

上述是**已有库之后的查询阶段收益**。已有来源任务获取、失败提取和建库成本没有重新计入，不能称为包含全部学习成本的端到端改善。也未加入跨查询修订缓存、共同来源 ready 缓存或专门的部分满足/MaxSAT 求解器；它们是投稿前仍需考虑的强对照。

精确来源式相对逐候选重检完整求解数没有差异，总时间中位数仅低 **0.75% / 1.41%**，只有三次重复，不能认定稳定的独立计算优势。相对来源并集式，仅额外避免 **3 / 15 次**完整求解；大多数收益来自已有失败知识，而非精确来源表达式本身。

**最优性与正确性审计。**无剪枝的原规划器共做 2,824 次顺序参照判断，验证每个返回候选之前都没有删除更少或同代价排序更早的 ready 候选。各组答案完全相同：

- 连续回放 186 项可行修订建议、1 项在授权删除范围内不可修订；143 项删一条，43 项删两条。
- 静态任务 420 项可行修订建议、12 项不可修订；313 项删一条、94 项删两条、12 项删三条、1 项删四条。
- 所有返回后缀都经原动作转移与历史监测检查，保留义务及 since 不变；精确来源式与逐候选重检在全部 **12,788 个授权删除子集**上等价。
- 全套回归 **897 passed**。无训练、模型 API 调用或物理动作。

**606 项修订建议不代表完成了 606 个原任务**，因为修订允许放弃一部分要求。目标是证明建议最优且可执行；并未证明这些删除符合真实用户的任务目的。不可删除范围和等价替代关系必须来自明确任务配置或用户指示。

**上一轮 nogood 强对照也补查了。**[事后覆盖审计](/root/autodl-tmp/ch3-planning/data/collections/fragment_repair_partial_control_20261117_v1/metrics.json)不计时，没有当作预注册第七组。相同修订算法若使用上一轮来源部分状态 nogood 库，需要 **336 / 663 次**完整求解；完整包络与十八核心拒绝表在所有 34 个状态上相同，所以能够得到与当前方法相同的 **287 / 581 次**。

连续回放的 4,236 个授权删除子集中，当前完整拒绝域比来源部分 nogood 多拒绝的 186 个子集全在首次任务修订阶段，受扰恢复阶段为零。新增八核心相对旧十核心在恢复阶段避免的 10 次完整求解，同样能被来源部分泛化解释。上一轮发现的实质新颖性缺口并未因此消失。

**文献边界。**[Kim 等的最小规约修订](https://arxiv.org/abs/1404.2289)已研究不可实现时接近原意图的可实现任务；[核心引导 MCS](https://ijcai.org/proceedings/2018/188)已有冲突与纠错集合的算法；[MaxHS 类隐式击中集](https://www.cs.helsinki.fi/u/mjarvisa/papers/saikko-berg-jarvisalo.sat16.pdf)已有从核心到最小代价删除的路线；[LTL-D*](https://arxiv.org/abs/2404.01219)已研究可行与不可行 LTL 任务的增量重规划。2026 年的 [From Errors to Proofs](https://arxiv.org/abs/2608.14771)还使用最小不可满足核心指导语言模型修复符号翻译。因此“把失败解释交回大模型重写”也不能单独作为新颖性落点。

这些邻近研究的输入、修订算子和保证不同，本轮没有复现其完整系统。这里只据原文确认相关思路已有先例，未声称性能胜过它们。

**当前建议。**把此实现保留为第三章新增的“失败知识辅助修订”模块，采用不在线缩核的简单版本。它证明旧失败知识能降低寻找可行修订的费用，且保持历史语义；这比继续包装拒绝掩码更有使用价值。但暂不把精确来源公式或最小删除本身定为独立小论文核心创新。

若继续投入此方向，优先补的是“允许怎样改、为什么仍保留任务目的”的问题：预先定义少量任务许可的等价对象/目标替换或未来顺序调整，与同样拥有这些算子、历史和失败库的标准最小代价修订器比较。仅增加算子数量或换成大模型生成建议不算新贡献；必须发现并验证新的问题结构、保证或明显计算差异后再定论文主张。
