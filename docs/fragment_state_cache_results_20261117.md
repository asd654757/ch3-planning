# 失败缓存强对照：认证迁移的额外作用及成本边界

本轮完成“普通失败缓存能否解释此前收益”的机制检验。相同来源失败、相同连续任务及相同规划后端下，状态绑定核心缓存减少 5 次完整求解，完整认证迁移减少 24 次，因而完整方法仍额外减少 **19 次完整求解**。其中 11 次能由同一具体核心迁移到新状态解释，8 次依赖更广的目标绑定。

这增强了“可验证、可迁移的失败约束片段”的机制证据。耗时结论较弱：统一匹配器后，相对失败缓存的在线耗时中位数降低 5.0%，三阶段总费用中位数降低 2.1%；存在明显时序波动，不能宣称稳定端到端加速。三组成功率和执行轨迹完全相同。

## 事先固定的比较

沿用上一轮全部 32 条序列、384 次修订及其受控扰动，H=8。执行阶段的 1,618 个决策快照、1,234 次指令尝试及 1,179 个支持事件均不改变。不是新的物理试验或独立任务集盲测。

| 方法 | 公共机制之外的失败知识 |
|---|---|
| fixed | 无新增失败核心 |
| state_cache | 相同八个小核心及完整来源状态，允许物体换名、green/return 互换及任务超集，共认证 96 个状态绑定点 |
| full | 同样八个核心，经类型化目标绑定和全状态认证得到适用守卫 |

公共机制包括旧十个核心、独立物体动作下界、相同来源精确缓存、合法后缀复用和原始完整规划器。状态缓存不是完整任务字符串匹配，也没有被禁止物体换名。

为隔离迁移机制，三组每轮都实际处理相同 384 个来源任务，均调用完整规划器 333 次并建立相同 333 条精确缓存。state_cache 和 full 对先前冻结的同八个失败执行相同最小化。来源流程、认证、序列化写入、重新载入核验和在线循环均实际计时。本轮没有用上一轮来源计时拼接总费用。

该共同来源流程与此前逐渐在线学习、来源完整求解降到 295 次的流程不同；本轮总费用结论限定于“相同失败证据”的机制消融，不能直接比较两轮百分比。

## 实现复核与最终计时版本

第一版状态缓存先查询旧库、再重新抽取 features 查询新库，完整方法则已经合并编译。这会给缓存对照额外增加特征提取及历史验证费用。第一版十轮数据完整保留，但其时间不作为最终公平结论。

修正版本将旧库和状态缓存合并，直接使用与 full **完全相同的 RegionBank.evidence 函数代码**、特征提取、包含消减和证明构造；未扩展缓存的逻辑覆盖。原代码和第一版归档未修改，使用独立新模块及驱动。新增等价测试验证全部合法状态与候选任务的命中相同，随后按原十轮顺序重新运行三组。

下表和所有最终费用结论只使用这一统一匹配器版本，未拼接第一版更快的记录，也未删除慢轮次。

## 正确性、额外覆盖与机制归因

| 指标 | fixed | state_cache | full |
|---|---:|---:|---:|
| 在线完整规划调用 | 288 | 283 | 264 |
| 认证核心提前识别 | 13 | 18 | 37 |
| 公共动作下界提前识别 | 134 | 134 | 134 |
| 合法后缀复用 | 1,183 | 1,183 | 1,183 |
| 来源精确缓存命中 | 0 | 0 | 0 |
| 完成修订 | 197 / 384 | 197 / 384 | 197 / 384 |
| 初次即不可行 / 执行中暂停 | 166 / 21 | 166 / 21 | 166 / 21 |
| 误拒 / 非法 ready 后缀 | 0 / 0 | 0 / 0 | 0 / 0 |

三组的全部语义轨迹与上一轮完全一致。独立分析重新运行 1,618 次完整求解，并回放 1,431 个实际返回的 ready 后缀。十轮是对同一批任务的计时重复，不能当作十个独立测试集。

状态缓存相对 fixed 省下的 5 次求解全部发生在受扰恢复。full 相对状态缓存进一步省下 **19 次，即 6.71% 的在线完整求解**，其中：

- 12 次位于任务修订后的首次判断；
- 7 次位于动作后的受扰恢复判断；
- 11 次存在与来源缓存完全相同的具体核心，但需要扩大其状态适用域；
- 另外 8 次在冻结库内需要超出领域对称变换的目标绑定；不能把这 8 次也全部归因于状态泛化；
- 移除新增三物体核心时，其中 15 次额外覆盖消失。这是覆盖消融，未另测删核心组时间。

这些判断由来源状态点、完整证书掩码和目标必要特征独立重算，逐项结果见[额外覆盖记录](../data/collections/fragment_state_cache_compiled_analysis_20261117_v1/extra_coverage.json)。

## 状态条件是否必要

保留公共后缀复用和动作下界的先后顺序，事后仅去掉新核心的状态守卫：在 **248 个实际进入约束检查、原后端判断为可行的请求**中，完整绑定集合会误拒 **115 个**；只使用来源对称绑定、同样省略状态条件，也会误拒 **97 个**。

该诊断未派发任何动作，未混入三组主实验，不将不安全消融当作性能对照。它说明“出现相似任务约束”不足以复用失败结论，需要保留状态适用条件或执行等价的正确性验证；它不证明本文的全部状态认证是唯一必要实现。

正确性理由仍是条件化的：若当前任务和历史的必要未来条件蕴含核心 K，而当前状态落在已认证的 `minimum_actions(K, state) > H` 或不可达区域，则完整任务在该模型和预算内不可行。历史已满足或未知事件可能满足的 visit 不作为必需未来访问，因而不会因片段迁移而把这些历史情况误拒。未命中则回退原后端。

单位为毫秒，均为预定十轮中位数。分项中位数分别计算，不应直接相加。

|---|---:|---:|---:|
| 来源获取、提取、认证及序列化 | 728.9 | 772.0 | 824.6 |
| 在线载入、重认证与准备 | 57.7 | 82.0 | 150.1 |
| 内部决策 | 1,336.0 | 1,303.1 | 1,153.5 |
| 完整符号执行循环 | 2,212.2 | 2,177.9 | 2,025.2 |

相对 state_cache，full 的决策时间中位数降低 **11.48%**，在线费用降低 **5.02%**，全部算法费用降低 **2.07%**。在线和全费用的配对轮次均为 **8 / 10 较快**；这是同一工作负载的工程结果，不作泛化显著性推断。

相对 fixed，full 的在线中位数降低 **5.86%**，全费用中位数仅降低 **0.87%**，在线及全费用均为 **7 / 10 较快**。

原始时间存在明显波动，必须同时保留不利统计：

| 全部算法费用统计 | fixed | state_cache | full |
|---|---:|---:|---:|
| 十轮均值 | 3,137.2 | 3,400.7 | 3,386.1 |
| 最小值 | 2,936.8 | 2,962.4 | 2,897.4 |
| 最大值 | 4,187.4 | 4,311.5 | 4,217.1 |

按均值，full 相对状态缓存仅降低 **0.43%**，相对 fixed 反而增加 **7.93%**。波动原因未被独立隔离，不能把慢轮归因于某个具体系统服务，也不能删除后重新宣传较大的增益。因此，全费用结论应写成**小幅、受时序波动影响的改善，尚无稳定端到端优势证据**。认证推广确实有更高准备费用；额外覆盖明确，不等于这些费用在所有运行条件下都值得支付。

## 本轮对第三章主张的影响

可支持的主张进一步明确为：**从规划失败中提取小约束核心，认证其绑定与状态适用条件，在任务修订和受扰恢复中安全复用，能够补足固定规则和状态绑定失败缓存的覆盖，减少原规划器重复求解。**

章节应围绕三个有对应实验的环节组织：失败核心提取、条件化迁移认证、执行证据下的复用与回退。性能主证据是额外避免的真实完整求解；时间必须同时报告构建与核验费用及波动。不能写成“成功率提升”“稳定机器人总耗时提升”或“可处理任意开放世界”。

本轮也没有独立证明小论文新颖性：状态相关冲突缓存和约束迁移已有相关研究，本实验检验的是本实现中这些机制的额外作用。当前证据仍局限于三物体、34 个合法状态、H=8 及已见生成规则下的连续任务。下一项需要的是冻结机制后的执行适用边界验证，尤其是观测不完整、预算变化和控制器能力不足时可靠停止或回退，而不是用更多同分布任务放大百分比。

新增状态缓存与共同匹配器共 11 项测试，全项目 **872 项测试通过**。没有调用生成模型，没有训练，没有物理仿真动作。
