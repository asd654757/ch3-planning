# 执行历史约束下的任务语义修订：开发协议

日期：2026-11-12。此版本先进行有限符号域的方法开发，不能称为物理机器人实验、开放世界能力或已成立的投稿创新。

## 问题与增量

已有 task_semantics 和 task_semantic_transfer 实现完整新指令解析、规则/搜索对照，并记录负结果。本实验新增：带生效时间的任务条款、只读执行证据、增量编辑事务，以及修订后任务与已执行历史的联合可完成性检查。自然语言解释仍可能错，引用原文不能证明完整理解。

对象 blue/yellow；位置 table/green/return；单手；green/return 容量各一；pick/place；动作后状态模型确定。初始任务已确认，向所有方法提供同一契约。历史来自显式确认、未确认或反证的事件，未确认事件枚举包含/不包含，最多六项。这是证据抽象，不是概率估计，也不保证枚举世界均物理可达。

## 语义

- at：最终位置；empty：最终空手；forbid：生效后禁止操作某对象。
- visit：生效后至少发生一次对应放置；before：两个 visit 的首次合格发生时间严格有序。
- 未修改条款保留其生效时间；新增/修改条款从当前历史游标之后生效。新增顺序可以引用旧 visit，因此能发现已经不可逆的逆序。要求“重新做一次”必须重建 visit 条款的身份/内容，不能把已经发生的历史删除。
- 新旧版本和状态/观测/历史摘要绑定。修订原子应用；悬空引用、重复编辑、过期回复等拒绝。冲突或证据不足时暂停执行，不能继续旧任务。
- 有界 BFS 寻找所有证据解释都可接受的共同动作后缀。找到则 ready；仅部分解释可完成或没有共同后缀则 need_observation；所有解释在给定动作上限内都不可完成则 conflict。后者不宣称无界物理不可行。

## 公平对照与冻结

比较增量编辑与完整重新翻译；二者获得同一初始契约、自然语言更新、状态、历史、能力和时间规则，同一模型、调用次数与输出 token 上限。二者共享时间赋值与后缀检查器。完整重译允许照抄现有契约；不能只给它最终位置。金标准新契约仅用于评分。加入忽略历史的机制消融和直接重译加差分约束的强对照后，才能归因到算法而非输出格式。

先开发机制测试和成对诊断案例，再小规模真实模型开发集。开发期间的失败完整保存；任何修改后另建运行目录。运行前冻结源码/案例 SHA256、模型、预算与顺序，不后台修改。开发集结果不能作为独立测试优势。独立测试必须采用新表述和历史组合，按案例族汇总，不把同一场景多随机种子当独立问题。

## 评价与停止准则

分别报告：修订语义精确性、未修改条款保留、历史判定正确性、可完成案例的有效后缀、冲突识别、必要补观测、协议/接口失败、调用和 token 成本。不会把所有拒绝计为成功；不得合并需要观测与不可完成。

至少完成可复现实现、机制消融、同信息真实模型对照和错误审计才判断研究去留。若强对照持平，就报告工程机制与适用边界，不称投稿贡献已证实。机器人桥接必须使用真实执行证据且单独报告；本符号实验不自动授权动作。
