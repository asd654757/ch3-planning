# 实际抓取超时后的模型剩余任务恢复：接线pilot

主题：由实际执行反馈触发真实模型调用，在支持的当前状态下生成剩余动作，不能只固定重试却称模型修复。复跑此前6技能任务的seed 0、1、2，两种设置共享首轮候选，保留旧失败数据。自然执行，无故障注入，默认旧协议不变，新功能需显式`--execution-recovery`。

## 授权分支

只处理pick的waypoint_timeout，不处理episode终止或任意故障。

1. 若已尝试闭夹爪，保留闭夹爪并做有界共运动观察；只有正向持物证据成立，才从holding状态调用模型生成place开头的后缀。负证据不推断为空手，不自动打开手释放可能持物。
2. 若trace确认只有开放夹爪的approach/descent，依赖此前支持的空手状态与“从未闭合”执行轨迹，做最多60步垂直开放夹爪撤退到0.24米，随后两帧观察验证物体静止、当前物体位置仍在此前已放置的可见注册区域。才从该区域上的物体/空手状态调用模型生成剩余计划，用新视觉绑定执行一次模型要求的pick。重复失败即停止。

第2分支仅限此前支持释放的region，不支持table故障定位；不是通用视觉空手估计，不保证开放夹爪不可能勾带物体。静止与支撑区域检验只是受控fixture下的有限证据，无碰撞安全主张。真值不参与授权。未知证据安全停止，不伪造状态。

## 模型与状态边界

模型收到最新图像、支持事实、失败trace、已完成搬运记录、剩余目标与动作契约；真实调用被审计为`phase=execution_repair`。严格解析、状态校验、最终目标与窄后端动作序列检查通过才执行。持物后缀必须place先行，已完成阶段不重放；未抓住时从当前阶段重新pick是失败动作恢复，不是重复已完成前缀。

旧模型初始候选仍共用，额外模型调用、接受与后续执行分别记录。失败probe和开放撤退额外动作属于恢复成本，不能说两设置实际控制步数相等。无恢复设置遇失败即停止，无相同探测后固定恢复对照，因此即使提高成功率也只能先归因于“观测确认＋模型后缀恢复”的组合，不能证明模型优于固定重试/符号搜索。需要之后加入同证据/同预算基线进行严格归因。

## 门槛

先确认实际触发与执行成功，不自动接旧扩量runner。若状态仍未知或模型恢复后仍控制失败，保留全部记录并继续诊断，不扩大同类失败。小pilot不能写成正式性能结论或完整ROUTED基准。

## 首次接线结果（040811，不能作为性能提升证据）

3个seed、两种设置，共6个episode。两种设置均成功1/3；共4次实际模型调用（3次共享初始规划、1次执行失败后的修复）。seed 0的模型修复后缀通过校验，但重新抓取仍在下降阶段超时；seed 1闭夹爪后持物证据不足，安全停止，没有请求模型凭空规划；seed 2两种设置均成功。

结论仅为执行失败→证据检查→实际模型剩余任务规划的链路已触发，尚未证明恢复带来执行收益。不能把修复后缀合法等同于物理恢复成功。

后续诊断版本为控制器trace增加目标位置、最终末端位置、误差向量、视觉绑定位置与观测ID，仅使用本体感知与已有视觉绑定，不读取物体真值，不放宽阈值。重新运行相同3个seed用于区分定位问题、控制目标不可达与夹爪接触问题。此诊断不自动启动大规模实验。

## 高度诊断与独立标定试验

041330诊断复跑仍为两种设置各1/3。seed 0二次抓取目标z=0.043 m，末端z=0.060495 m，xy误差均小于0.0002 m；seed 1闭合阶段末端z=0.058867 m，相对目标z误差0.015867 m。这些数据支持高度目标/接触可达性问题，而非明显的水平控制偏差；尚未由接触记录证明具体碰撞根因。

独立标定pilot将视觉平面至末端抓取目标偏移由0.015 m改为0.030 m，两种设置统一使用。保留默认旧偏移、旧数据、0.015 m到点阈值、35步夹爪驻留、RGB持物及释放检查；不使用物体真值控制，不自动放宽成功条件。新偏移是固定后端的可选几何配置，不是模型创新，不可将其改善归因于修复方法。3个seed仅用于可执行性检查；若两种设置都改善，也不能据此主张模型修复优于无修复。

标定pilot（路径记录在`/tmp/model_contact_calibration_pilot_output`）完成6个episode，两种设置各3/3成功；3次实际共享初始模型规划，0次执行修复调用。结果支持在这3个seed上修正高度配置后六技能连续任务可执行，不证明普适成功或修复性能增益。保留此前两批失败结果，不混合成同一协议统计；尚未启动扩量实验。
