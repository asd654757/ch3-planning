# 执行反馈v2：为模型规划修复补齐观测后置条件

主题：执行结果证据决定任务进度，未完成任务从受支持的当前状态调用真实大模型生成剩余计划。固定视觉/控制后端只是支撑，不声称其定位修正是模型创新。

## 版本化修正

开启--feedback-v2，旧默认行为不变，两种设置使用同一版本后端。

1. 初始接触前RGB估计两注册区域的静态参考，控制与观测检查均记录其来源。后续被遮挡中心估计不覆盖初始参考；当帧区域仍须可检测，记录新估计。仅静态fixture可用，不能迁移为移动目标模型。
2. Release Checker只检查此前持物、开放撤退、物体静止及与手分离；不把到达任务区域当成空手条件。
3. Observed Goal Checker对两帧释放后位置与初始图像区域参考比较。观测冲突/缺失/不稳定返回unknown，不推进进度。固定阈值与旧评分相同，不修改独立评分。
4. 目标未满足且空手证据成立：物体被记为on(observed_support)，不伪造on(goal)或table；模型收到图像、失败记录、剩余目标，生成pick/place剩余后缀。后端允许一次有界重做，持物与后置目标都再检查。
5. place下降超时且还未发送释放命令：保持夹爪闭合，正向共运动确认持物后调用真实模型place先行后缀。未知即停止，不能直接打开夹爪或假设已经放好。

模型后缀需结构、状态、最终符号目标与窄后端序列全部通过才执行。已完成前缀不重放；支撑类型与禁动对象保留。模型可以拒绝，不自动把错误输出替换成正确计划。

## 有限证据边界

初始参考与释放后物体观测不共享“刚执行的放置目标估计”，可减少遮挡偏差自我确认，但仍共享标定与平面假设，不是统计独立的双传感器。多帧稳定不能证明无系统偏差。当前没有经独立校准验证的误差界，observed_goal会明确记录calibrated_error_bound_available=false，不能声称完成判断已具备严格视觉安全保证。

真值仅在执行结束后独立评分。评分失败但在线通过仍需如实报告；不把评分真值用于触发恢复。持续保护约束目前为离散评估采样，非连续碰撞约束。

## 开跑门槛与数据分层

先6个诊断seed（0、1、2、15、26、31）两种设置共12次，包含旧正常与失败样本；此集合不得当正式性能结论。

随后准备新seed 33至42的配对pilot。扩量门槛：完整日志，无状态伪造或已完成前缀重放，支持证据与API调用有审计；还须观察到至少一次真实执行修复被接受并完成，才能开展“模型恢复收益”大规模比较。若仅定位修正让两设置均成功、没有修复调用，则仅有可执行性证据，不能自动跑大量重复样本宣称修复有效。

如进入正式恢复对比，应增加同证据同预算固定恢复对照，区别状态确认/重做动作与模型贡献。不随结果挑seed，不削弱对照，不故意保持定位缺陷制造收益。新pilot或正式集另目录存储，旧失败保留。

## 自然布局难度验证（第三层，独立协议）

前两层分别12/12与20/20成功，且均无执行修复调用，因此不自动扩量恢复基准。进一步预先固定seed 43至54，两种设置共24次，将物体初始y随机范围从0.68±0.025 m扩大到0.68±0.080 m，x不变。两设置同seed同场景，无执行故障注入，预算/评分/模型参数不变；图像输入与实际视觉定位随布局变化。此批是自然初始布局变化，不是任务语义/开世界扩展。仍使用上述恢复扩量门槛；结果不与前两批合并。若无成功修复触发或在线目标误接受，停止扩量并明确记录限制。
