# 六技能大模型规划自然执行pilot与扩量门槛

## 主题与难度

直接检验大模型初始计划、校验拒绝后的诊断修正及持续执行，不再扩大固定计划观察实验。任务：蓝物体先搬至绿色区域并释放，再重新抓取搬至返回区域，最后黄物体搬至绿色区域。6个连续技能、两次状态边界、一次从目标面重新抓取，均在同一episode中执行。中间蓝物体到绿区是任务的时序要求，不能因为最终目标相同而跳过；范围检查拒绝跳过步骤的模型计划并记录错误。模型动作才进入执行，不自动补全成参考动作。

两设置共用一次真实VLM首轮图像条件候选，输入自然语言及受控符号初态；都使用两轮观察预算。MODEL_NO_PLAN_REPAIR拒绝即停止；MODEL_DIAGNOSTIC_REPAIR计划拒绝时最多一次诊断修正。阶段实际释放证据通过后校验模型剩余动作，必要时从支持状态调用模型修正，不能重复已完成阶段。第二次blue pick是任务要求的下一阶段，不是重复执行前缀。

总horizon统一1500，单技能预算和评分不变；较长horizon是为6技能留足正常执行时间，不是人为制造超时。已放置物体再抓取使用已知支撑平面假设0.028米，当前目标仍来自RGB而非真值。故障不注入，未知持物/释放和控制失败仍停止，本版尚无通用执行故障状态估计与重规划。不能把观察重试当模型修复。

## 预固定数量与门槛

先运行seed 0、1、2（两设置共6次）验证长任务的真实执行链与模型调用。若有至少2个seed完成全部6技能且无接线/输入复用异常，再从独立的seed 3至32运行30个seed、共60次，避免把开发seed混入扩量统计。若执行后端阻塞，不扩量，先定位规划/视觉/控制层。若全都正确、修复未触发，也如实记录，不加注入错误制造优势。

全量报告初始候选拒绝、实际诊断修复调用、恢复后执行、最终完成及失败层级；初始计划拒绝后的改善与执行失败恢复须分开。本实验仍是单一时序模板的受控采样，不是通用高难度任务集合或完整ROUTED基准。

## 状态规则版本边界

旧状态规则只允许从table抓取，不能执行“在绿色平面放置后再次抓取”。本版本新增Validator的显式可选`pick_surfaces`，仅长任务声明已知平坦green_region/return_region可抓取；旧调用默认仍只有table。新选项贯穿状态模拟和首错前缀状态计算，不通过把on(region)改成on(table)伪造当前状态。测试验证旧协议拒绝而新声明允许。该规则扩展不证明任意物体堆叠可抓取，也不表示碰撞安全。
