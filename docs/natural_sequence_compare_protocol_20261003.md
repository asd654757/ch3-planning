# 自然持续执行的观察恢复对照（预固定pilot）

30个仿真seed（0至29）×两种设置，共60个episode。每个episode只初始化一次，同一seed共享相同场景构造与初始位置分布，两设置按seed奇偶交替顺序运行。固定任务为同一场景中的蓝物体→返回区域、黄物体→绿色区域（4个连续技能），比单物体pick/place长，但仍是一个任务模板，不声称通用困难任务集。

- STOP_ON_FAILURE：定位、持物、释放或控制失败则停止，不做额外重新观察。
- BOUNDED_REOBSERVE：唯一差异是区域定位失败时最多两轮闭夹爪小幅抬升、重新确认持物及重新定位；其他失败同样停止。

不注入掉落、超时、黑屏、目标移动等故障；不人为缩短技能步数。控制器、定位阈值、单技能预算、总horizon1000、终态评分规则完全相同。恢复设置可能多执行观察动作，必须报告额外观察次数；相同horizon不代表实际动作成本相同。物体真值仅独立评分，不用于在线授权。模型调用为0，因此只能解释为观察恢复/控制接口收益，不能称为完整ROUTED或大模型修复优势。

30个seed是受控已知颜色与几何下的位置采样，不是30个独立自然语言任务。不选择失败seed扩量，不按结果剔除案例；报告全部60个分母、配对胜负、失败层级和额外观察次数。原3个seed的开发实验不混入本轮统计。本轮仍采用原有单帧终态位置和离散蓝物体保护采样，不新增稳定性定义，也不冒充连续稳定性验证。

脚本：`scripts/natural_sequence_compare.py`。原始episode结果、图像、协议与summary均保存在独立目录。先确认确实执行，随后停止实时监控；跑完再核对是否值得接入模型剩余任务恢复。无区分度也如实保留。
