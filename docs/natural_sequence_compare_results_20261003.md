# 自然双物体持续执行对照结果

数据目录：`data/collections/natural_sequence_compare_20261003_030333/`。预固定协议见`natural_sequence_compare_protocol_20261003.md`。

## 完整性与结果

60/60 episode完整，30个seed每个运行两种设置，无缺失或重复。每次只初始化/reset一次，所有模型调用为0，没有注入执行故障。两设置每个seed的初始蓝物体pick/place控制轨迹一致。

| 指标 | STOP_ON_FAILURE | BOUNDED_REOBSERVE |
|---|---:|---:|
| 任务完成 | 15/30（50%） | 30/30（100%） |
| 额外目标观察尝试 | 0 | 21 |
| 模型调用 | 0 | 0 |

恢复设置的额外观察次数分布：15个episode为0次，9个为1次，6个为2次。平均全部episode为0.70次，触发恢复的15个episode平均1.40次。观察成本并非免费：包含闭夹爪抬升、共运动探测及新RGB定位，本表不是总动作步数或运行时成本比较。

配对结果为改善15、退步0、同结果15。描述性exact双侧McNemar p=0.00006103515625（15个不一致配对），仅适用于这个固定模板下seed采样，不能推断到独立任务分布或开世界。任务成功为原协议终态位置评分与离散保护位移，不含连续终态稳定性检测。

## 失败来源与恢复边界

无恢复失败seed：1、4、5、7、8、11、12、13、15、18、19、21、23、28、29。全部在yellow_place之前的目标区域定位阶段耗尽观察预算而停止；这些案例没有执行黄色放置，因此不能说放置控制本身失败。恢复设置在这些配对seed上通过1或2轮额外观察继续完成。故障来源是自然执行姿态下的目标观测不足/歧义，不是人为故障注入，但也不是从真实应用采集的自然错误分布。

恢复设置30个终态均满足位置评分，已完成蓝物体的两次保护采样位移均为0。未完成的无恢复案例没有完整终态评分，不因缺失终态评分当作成功。离散采样不能排除瞬态碰撞或扰动。

## 论文可用结论

可写：“在受控已知颜色的持续双物体场景中，在不注入故障的条件下，有界执行观察恢复将任务完成数由15/30提高至30/30，新增观察尝试共21次。”

不能写：“ROUTED达到100%”；“大模型修复明显优于其他方法”；“开世界视觉恢复成功率100%”。两设置均为固定参考计划与固定后端，差异是观察恢复，并未检验模型重规划、错误感知路由或模型必要性。STOP_ON_FAILURE也不是强重试/重规划基线。本实验是执行接口的支撑证据，不是完整主方法贡献归因。

## 后续建议

现有自然错误全部集中于目标可见性，继续增加相同模板seed大概率仍主要测观察能力。下一轮应接入实际模型剩余计划，并同时保留统一观察预算的无规划恢复基线：两设置都能重新观察，只有一个能按实际当前状态修正剩余计划。这样才能区分观察能力与规划恢复贡献。先小规模验证，若自然执行未触发重规划就如实报告“未触发”，不为了获得优势注入故障后仍称自然执行。
