# 持续多物体执行参考门槛（非模型实验）

脚本：`scripts/persistent_reference_sequence.py`。

## 预固定范围

3个仿真seed（0、1、2），每个只reset一次：蓝物体搬至洋红返回区域，再将黄物体搬至绿色区域。复用现有两区域场景，暂不新增第三区域。无模型调用、无掉落注入、无恢复重试。目的仅为核对后端能否在持续episode中连续搬运两个物体，不代表主方法性能。

固定颜色分割、静态相机标定与已知平面高度提供控制器目标。初始空手与物体在桌面来自受控fixture；非开世界状态估计。抓取后必须满足RGB共运动证据，放置后必须满足RGB到达与开放夹爪撤退后的静止/分离证据，才能继续。该释放证据只针对当前唯一被持物体，不表示场景只有一个物体，也不是通用接触或空手识别。

执行总horizon为1000，原控制器单技能预算不变。任何定位、证据或控制失败保留失败案例并停止，不追加重试、不reset恢复、不跳过失败seed。

## 真值信息边界

物体真值只用于独立评分，绝不进入目标绑定或在线授权。两个终态位置必须在各区域中心的x/y容差（0.025、0.018米）内，物体z在0.015至0.06米内。蓝物体首次完成后的位移在黄物体抓取后及最终时采样，最大值不得超过0.015米。该指标仅是**离散采样**，不能声称全过程无扰动或碰撞安全；瞬态位移可能漏检。这里没有10步终态稳定性检查，不能与已有稳定性协议的正式成功率混用。

place dispatch的对象绑定仅满足接口身份/来源契约，后端实际目标为新的区域视觉绑定；后端不使用历史对象位置决定place运动。

## 后续门槛

先确认实际执行进度，再停止监控。跑完按全部3个seed核对失败层级。若门槛失败，先诊断控制、视觉证据或几何问题；不马上扩展模型实验。若通过，仍须补充第三区域可达性、终态稳定性及执行扰动方案，才冻结多目标恢复正式协议。
