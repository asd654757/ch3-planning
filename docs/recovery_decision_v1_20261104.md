# 恢复决策 V1：可计算原型及进入实验证据的条件

## 当前状态

实现：`ch3/repair/recovery_decision.py`。仅提供建议，不接管现有 Supervisor，
不修改冻结结果，不调用模型或仿真，不将任何预测写成目标完成证据。
诊断：`python -m scripts.recovery_decision_diagnostic`。
当前全部概率、损失与边界值均为显式标记的合成参数，没有经验优势证据。

原型用于验证选择逻辑，不是新颖性声明。有限步信念空间决策与信息价值已有
研究基础；需要进一步核查相邻的机器人恢复、元推理、观测选择工作。

## 问题与计算

输入：绑定实际观测 ID 的局部假设分布 b、共同证据保护允许的选项、剩余
观测/命令/模型调用/时间预算，以及独立标定的动作-结果模型。
动作：continue / observe / retry / replan / stop。
输出：建议动作、各可用动作的模型价值、所依据的观测 ID 和模型来源。

实现两步前瞻：

    Q_d(b, B, a) = -loss(a) + Σ_o P(o | b,a) V_{d-1}(b', B-cost(a))
    V_d = max over admitted actions, including stop with value zero.

成功终态奖励 1，失败/停止奖励 0。边界 continuation value 必须另行声明来源；
诊断设置为 0。成本与终态收益使用相同效用单位，预算仍为独立硬约束。
模型结果按可见 observation label 聚合，再做贝叶斯更新；不得把隐藏解释
作为可见标签传给决策器。相同可见失败可以改变不同解释的后验权重。

深度是恢复宏动作数，不是机器人低层控制步。重规划的模型必须包含规划之后
的校验、执行及结果成本，不能把 API 返回成功当任务完成。V1动作成本为固定
整数资源及固定非负损失；不支持随机时长，实际接入须用保守上界或扩展模型。
非终态宏动作造成的物理改变应进入 next_state，不能假定所有再观察都无扰动。

## 硬边界和已知限制

- 动作需同时满足共同 guard、模型在全部非零假设上有支持，以及剩余资源足够。
  模型缺少的假设只允许 stop；不得凭空补概率或假定某种失败解释为真。
- `update()` 只能用于执行后实际取得的非终态观测，需新观测 ID 和重新计算的
  guard 权限。预测分支仅作内部搜索；终态模型标签不会生成 Evidence.TRUE。
- 前瞻分支保守继承当前 guard 权限，不能猜测未来 guard 将放行什么。因此，
  如果当前权限完全禁止后续命令，原型可能低估获取新证据的价值。实际接入前
  应实现共享、可审计的证据到权限映射；不得为本文方法独享放行机制。
- 有限深度、边界值、错误概率和损失权重均可能改变选择。当前没有概率校准、
  鲁棒优化保证、开放世界保证或实际安全保证。stop仅是不再派发新命令。
- 本模块不生成 pick/place 序列；原有校验、当前观测绑定和独立终态评分继续保留。
- 有成本的纯观察若不改变可用决策且无物理作用，模型不应赋予它额外价值。

## 与规则比较要回答的问题

只在以下机会存在时有必要做后续试验：相似异常表象对应不同恢复选择；
可获得的观测或历史能帮助区分；选错会造成实际任务或资源损失。
若状态已明确且唯一恢复规则足够，报告规则足够，不扩展求优实验。

合成诊断包括有效/无效观察、已知可继续/可重试、仅够一次操作、模型外假设。
固定重规划、观察一次后规则作为算术对照，与原型共享模型、观测更新、预算、
权限、深度和边界值；它们不是已复现的强 LLM 基线，也不是调优规则的替代。
诊断中的理论效用不是实测成功率，不允许写成“提升若干个百分点”。

## 真实数据之前先过的门槛

1. 为现有控制器实现可执行的恢复宏动作，逐项记录允许条件和实际资源消耗。
   不注册实际无法执行的换抓法、换路径或新视角。
2. 用真实连续执行案例检查恢复歧义：只给决策器实际公开的观测；扰动名称、
   真值状态、评分均隔离。已知颜色、标定及固定任务仍是受限先验。
3. 开发集估计先验、结果概率、观测区分能力、成本与边界值。保留原始计数、
   来源、置信区间，检查概率/权重扰动和深度1/2下决策是否稳定。不用评测集标定。
   这属于统计标定，不是训练新的底层策略；当前尚未完成。
4. 同一初始恢复快照分支试验可用于开发标定，需记录克隆/恢复状态和物理随机性；
   分支样本共享来源，不当独立任务。回放不产生未执行恢复动作的物理结果。
   正式执行仍每回合一次初始化，方法内恢复不重置。
5. 如果现有信息无法区分失败解释，或不同解释最佳选择相同，停止该条件扩展。
   如果没有稳定模型或方法只靠权重微调赢，暂不做正式实验。

## 正式比较（尚未启动）

主要对照：同模型直接重规划，允许相同的观察/重试/停止选项；开发集调优的
固定规则；同输入的简单决策树/评分规则；有限步恢复决策。
“永远重规划”只作辅助对照，不能取代上述强基线。
同一观测工具、动作库、独立目标判据、执行保护、控制器和最大资源预算。

主要结果为预先固定预算下的最终任务成功率，所有分配的失败和停止保留。
同时报告实际耗时、调用、控制步骤、无效观察、失败重试及非法动作承诺。
观察、动作、调用预算分别统计，不能用不同单位换算制造优势。
正常/无歧义情况必须保留，检查额外决策开销。

消融：深度1；移除历史更新；固定预算特征。禁止向消融提供不同隐藏信息。
开发材料、冻结评估布局/扰动日程分开；按配对条件报告，保留空结果及负结果。
不把目前两物体受限任务的结果称为开放世界泛化。
