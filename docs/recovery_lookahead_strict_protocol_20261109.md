# 前瞻恢复：严格验证协议（结果揭示前固定）

## 目标和成功判据

目标是检验有限步前瞻能否在同信息、同恢复能力、同预算下优于调优规则，
而不是通过增加提示、隐藏基线观测或选择赢的条件获得差距。
目前没有保证该假设成立；此前空/负结果全部保留。

主指标：固定资源上限下，经独立终态判据确认的任务完成率。提前停止、
解析/API失败、动作失败均计入原分母。预算含观察动作引起的机器人运动；
不同资源维度分别统计，不用手选效用权重替代主指标。
次指标：实际控制步、传感器采集次数、调用、端到端耗时、无效重试与观察。
协议违规单报，不把合法停止计为成功。

## 阶段0：观测选择的物理可行性（本轮实际运行）

固定开发seed 920、921、922，不因结果补挑seed。
完整交叉：screen absent/present × after_pick/controlled_release，共12次。
使用已注册相机 corner2/topview/corner；初始抓取统一由corner的RGB绑定。
每回合一次reset；两轮横向40mm共运动探测；每个采样时刻按固定顺序采集
所有相机，同一时刻各相机之间不步进仿真。逐相机独立计算证据，不混像素。
公开初始图像、控制回执、实际命令均允许基线使用。扰动名称和真值隔离。
所有失败与无效视角保留，禁止看到结果后换阈值、换视角或移动遮挡物。

本阶段只是全信息开发审计：同时采集所有相机不是在线决策策略。
计入所有实际render和探测成本，不能假定这些图像在线免费可得。
记录视觉继续权限而非宣称任务完成；有图像不等于持物或目标达成。

进入下一阶段的条件：必须观察到至少两种有实际证据价值差异的可用观测，
并查清这种差异是否在同一公开条件下可预测。如果只有一个视角普遍最好，
“总选最好视角”应保留为强规则；不能只用“重复坏视角”做对照。
若当前状态已直接决定动作，则不把这些案例包装成前瞻的必要性证据。

## 阶段1：更严格的在线条件（未达到门槛前不启动）

冻结交叉因素：正常、暂时反馈故障、持续反馈故障、接触前超时、接触后效果失效。
暂时/持续故障的标签不暴露给策略，仅暴露实际可用设备状态和观测。
在每种条件保留所有预算档，包含只够一次恢复、够观察加恢复、够多次恢复。
预算以开发运行的宏动作实际成本上界确定，数值须在独立评估前冻结。
不把不支持的接触后重抓或未实现的重规划注册成可用动作。

基线共享工具和证据门槛：
1. 当前信息下的直接重规划agent，可请求同样的观察/重试/停止。
2. 开发集调优的固定规则，覆盖观察次数、重试次数、相机优先顺序和预算判断。
3. 同输入的简单决策树或线性评分，使用可见历史与预算。
4. 有限步前瞻；与深度1使用相同结果模型和同一边界值。

若本阶段不使用模型，只能称为前瞻与规则比较，不称优于LLM直接重规划。
非模型宏动作替代不能冒称已复现LLM基线。

模型先验、转移、观测概率及成本来自单独开发数据，保存计数、不确定性和
校准检查。小样本2/2不设成真概率1。不得在线读仿真真值为本文选择动作。
观测改变未来执行权限的规则必须共享给所有方法，不能用预测成功绕过证据。

## 阶段2：前瞻贡献的判别

开发完成后，使用未使用过的seed960–979，冻结代码、模型、预算、条件及方法。
在同seed/条件/预算配对比较，报告逐条件结果及预先固定等权总体。
总体权重不按哪个条件赢来调整；对照始终含正常和无信息价值情形。
方法运行顺序交替，若有随机控制使用配对外生扰动日程。

配对成功差、95%区间与配对检验都报告；多个主比较说明多重比较处理。
不能将非显著解释成等效；成本优势需与成功率及失败构成一起报告。
样本量不足以支持优效时结论为未证实，不事后加样本直到显著。

必要消融：深度1、无历史后验更新、移除预算适应；逐个改变机制。
若前瞻仅优于故意不看预算的规则而不优于调优规则，不宣称独有算法优势。
若优势只存在于真实模型已知或成本精调的情形，明确限制适用范围。

## 停止条件

观测无价值差异、固定视角规则已足够、动作模型无法标定、核心恢复动作
没有证据授权，任一情形出现就停止正式扩展并记录缺口。
只有技术和证据门槛通过才进入在线比较，不以“pilot先赢”为入场条件。
