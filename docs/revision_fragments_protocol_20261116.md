# 从失败中提取可验证约束片段：首轮离线协议

本协议在新有限组合测试运行前冻结。目的：把已经观察到的候选失败转为可审计的有界冲突片段，检验变量化迁移与误拒边界；不是预先宣称已有方法创新或开放世界安全保证。本轮不调用模型、不训练权重、不做物理实验，不覆盖原有实验。

## 来源与允许的推断

使用 `context_memory_validation_20261116_v2` 的真实模型拒绝记录作为本轮**开发来源**。它已经被研究者查看，不再充当本轮盲测数据。重新运行每个被拒候选的现有检查器，只有拒绝可以重现时才允许触发提取；记录文件哈希、案例、方法、轮次与候选哈希。不读取 expected_status 或任务族标签来选择规则。

候选无效不蕴含任务不可行。提取前使用必要条件松弛：保留 at/empty 的终态要求、forbid 的未来部分；只在所有已确认/未知历史中均无符合起算点的 place 时，将 visit 视为待完成的未来要求；丢弃 before 和过去的禁令违例。它弱于每个可能历史分支的实际任务，因此若此松弛都不可行，每个实际分支也不可行。松弛可行时弃权，不能把搜索到一个坏后缀当成不可行证明。

## 提取与认证

从松弛条款及当前物体位置出发，依次尝试删除原子。对保留的位置事实，枚举整个有限域中所有相容状态；必须都没有 8 步内的合法后缀才允许继续删除。使用预先指定的正向、反向两种贪心删除顺序，得到包含意义上的极小片段，**不是最小基数、不是所有极小核心枚举**。

物体替换为同类型变量；容量为 1 的绿色/返回区域替换为区域变量；table 和 hand 保留独立语义。不同源实体的变量使用单射绑定，不把两个不同物体错误合并为一个。规范化后去重，不能根据新测试结果人工补一条规则。

认证遍历变量所有合法绑定及相容状态，使用现有有界求解器核验每个实例。删除每个原子必须有一个可完成的反例，保存反例状态与动作后缀。模式文件不能凭自报 verified 被信任，载入 VerifiedBank 时重新认证；记录领域及推理实现哈希。领域/代码变化或查询动作上限超过认证上限时不得沿用旧结论。

在线只匹配实际任务、位置和经过历史检查的待完成 visit，不再搜索。匹配返回带绑定和支撑原子的有界 conflict 证据；不匹配返回 None，由同一原后端处理。片段既不增加事实，也不擅自修改任务、生成替代计划或将 unknown 变成已确认。认证只覆盖既有蓝/黄双物体、两个单位容量区、无限容量桌面和单手领域；同类型更名不是跨领域或任意物体数量的证明。

## 测试与对照

测试输入生成后、结果计算前冻结并保存哈希：

- 完整枚举 13 个合法状态，以及 15 个原子条款池中 0 至 3 条的全部组合。池包含每物体每目标的 at/visit、每物体 forbid 和 empty；共 7,488 个潜在输入，剔除与来源任务具有相同“松弛任务＋状态”签名的输入。它是有限组合的覆盖测试，不是数千条独立机器人试验。
- 额外 48 个时间边界探针，交叉改变物体角色、区域、事件 confirmed/unknown/refuted、生效锚点及是否保护阻挡物。尤其要检查已经完成的必经、未知历史和解除保护时不会错误沿用旧片段。

四组共享同一输入和 8 步预算：每次重新求解；直接复用极小核心（保留源物体与区域常量）；变量化片段复用；**人工编写的领域不变量＋同一求解器**。人工基线覆盖容量冲突、同物体不同终点、受保护对象目标不满足、受保护对象待执行必经、受保护阻挡物和持物保护与空手冲突。它不应故意弱化，也不称对某个文献系统的完整复现。

每组未命中都实际调用同一求解器，记录调用数和局部耗时；基准重新求解也提供离线真值。主要检查：误报 conflict 数、三态判断一致性、片段命中数、变量化相对带常量核心新增覆盖、相对人工不变量的覆盖差距。报告提取与认证的真实求解调用和时间，不能把它们隐去后宣称总成本更低。模型调用节约、模型正确率提高、物理成功率和系统端到端加速均不在本轮指标范围内。

## 判定标准

出现一个误拒就不把当前匹配机制接入实际拒绝门槛，先保留反例再修正版本；不静默覆盖原始记录。若变量化提高覆盖但人工不变量同样可以做到，只承认自动提取和复用机制已实现，不宣称新的规划能力。若无法证明相对现有 nogood/冲突核心复用方法新增了什么，也不称可投稿的方法创新已经成立。

## 已检索的相关研究与区分点

- [COAST，2024](https://arxiv.org/abs/2405.08572)：将运动细化失败转为规划约束。失败转约束本身不是新思想。
- [Learning to guide task and motion planning using score-space representation，2018/2019](https://arxiv.org/abs/1807.09962)：在问题之间迁移用于指导搜索的约束。本轮不是训练 score-space 预测器。
- [VIZ-COAST](https://arxiv.org/abs/2510.25548)、[作者项目](https://commalab.org/papers/vizcoast/)：用视觉语言模型提出可在新实例复用的规划约束，并利用细化失败更新约束；本轮没有几何细化或 VLM 约束生成。
- [SCLPlan 作者项目](https://gbyrd-research.github.io/Constrained-Natural-Language-Action-Planning-for-Resilient-Embodied-Systems/)：符号规划与语言规划结合、动作前置条件验证；不能把已有前置条件换成“经验约束”就视为新贡献。

本轮具体实现是**失败触发的松弛冲突核心提取、类型化更名和有限域认证复用**。这些是研究原型的工作定义，并非已经证实区别于现有规划学习方法的创新声明。新增领域知识并非从单次失败中凭空推断，核验仍依赖既有领域模型。
