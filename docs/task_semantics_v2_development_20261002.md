针对v1保留的12条开发指令：

- 将输出改为紧凑填写式contract+evidence，不把完整Pydantic JSON schema塞入提示。
- 明确可用目的包含table；“放回桌面”必须生成位置目标，不仅hand_empty。

仍为显式状态、已知颜色候选、冻结单帧的符号诊断，不是在线视觉闭环或开放世界。原v1结果保持不变，v2在独立目录全部记录。
