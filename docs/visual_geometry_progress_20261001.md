# 视觉目标几何接口

新增 `ch3/execution/visual_geometry.py`：由原生图像像素、针孔相机内参、光学相机到执行坐标系的刚体变换，以及显式平面高度假设，计算射线—水平平面交点，并构造 `visual_estimate` 目标绑定。

相机约定 x 向右、y 向下、z 向前。MuJoCo 相机坐标与该约定不同，后续导出标定时必须显式转换。当前渲染图翻转了两轴，因此输入本模块前必须将像素还原到原生图像坐标；不能直接拿显示图的框中心计算。

该模块没有物体 pose、segmentation 或 evaluator truth 输入。平面高度是假设，不是物体真实高度；对于高物体、遮挡、倾斜表面和非抓取中心，结果可能不适用。源标签仅描述数据来源，不能保证感知正确。

检查覆盖了尺寸、坐标系、有限数值、合法内参、刚体旋转、图像边界、平行射线和后向交点。8 项新增测试与此前相关测试共 54 项通过。

尚未完成：当前场景的标定导出、图像方向转换集成、目标像素独立评估、工作空间/碰撞检查、实际多物体控制器。本轮没有调用模型、没有执行抓取、没有新增成功率数据。该接口不生成抓取姿态或无碰撞轨迹。

下一步优先导出固定相机的公开标定，验证投影与反投影约定；之后才将经过核验的目标绑定交给固定 pick/place 执行器。push/press 保留为后续技能扩展，不因接口支持名称而声称已完成多技能视觉执行。
